# Количественные финансы: от эксперимента к пониманию

Доступный путь от первого набора рыночных данных к сигналам, рискам, портфелям и воспроизводимым исследованиям. Учитесь с помощью **8 блокнотов Jupyter, 5 исследовательских лекций и 7 демонстраций в браузере**.

**Языки материалов:** это руководство и навигация доступны на десяти языках. Блокноты, лекции и большинство сопроводительных документов пока написаны **на упрощённом китайском**; переключение языка README не переводит содержание курса.

Предварительный опыт в количественных финансах не требуется. Основы Python помогут при работе с блокнотами; сначала можно просто читать HTML-уроки. В каждом уроке следуйте циклу: **прочитать → запустить → изменить одно допущение → объяснить результат**.

### Как читать HTML-уроки

**GitHub показывает исходный HTML-код; ссылка на файл репозитория не запускает урок.** Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте файл `extras/lecture-0N/index.html` в браузере. Пять страниц лекций и семь демонстраций можно изучать локально без интернета. Внешние ссылки и загрузка рыночных данных по-прежнему требуют подключения.

Другой вариант — выполнить из корня репозитория:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/extras/lecture-01/` (для остальных лекций замените `01` на `02`–`05`). На macOS/Linux используйте `python3`, если команда `python` недоступна. Остановите сервер сочетанием `Ctrl+C`.

Лекция 01: стрелки или Пробел — переход между слайдами, `N` — заметки докладчика, `O` — обзор, `F` — полноэкранный режим.

## 2. Настройте среду для блокнотов

Используйте **Python 3.10+**; для начала подойдёт Python 3.12. Установите Git для клонирования либо скачайте и распакуйте ZIP. Выполняйте следующие команды в терминале. Прямые пути к интерпретатору среды позволяют обойти проблемы с её активацией в оболочке.

<details>
<summary><strong>Windows · PowerShell</strong></summary>

```powershell
git clone https://github.com/ThreshoLdnnis/Quant-for-babies.git
cd Quant-for-babies
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

Если вы скачали ZIP, откройте PowerShell в распакованной папке репозитория и начните с `python -m venv .venv`.

</details>

<details>
<summary><strong>macOS / Linux · Терминал</strong></summary>

```bash
git clone https://github.com/ThreshoLdnnis/Quant-for-babies.git
cd Quant-for-babies
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m jupyterlab
```

Если вы скачали ZIP, откройте терминал в распакованной папке репозитория и начните с `python3 -m venv .venv`.

</details>

Jupyter выведет локальный URL в терминале. Откройте его в браузере, выберите `notebooks/phase1_intro/01_什么是量化金融.ipynb` и выполняйте ячейки сверху вниз (`Shift+Enter`). Убедитесь, что блокнот использует только что созданную среду.

| Группа зависимостей | Назначение | Откуда устанавливать |
| --- | --- | --- |
| Jupyter, NumPy, pandas, Matplotlib, seaborn | Выполнение блокнотов, таблицы и графики | [Зависимости в корне](../../requirements.txt) |
| yfinance, AkShare | Примеры с рыночными данными; требуется интернет | Зависимости в корне |
| scikit-learn | Инструменты машинного обучения в учебной среде | Зависимости в корне; последующие главы об ИИ пока планируются |
| Зависимости отдельных лекций | Офлайн-практикумы; для лекции 04 также нужен SciPy | `requirements.txt` в папке соответствующей лекции |
| Необязательные пакеты визуализации | Экспорт рисунков практикумов | `requirements-plot.txt` в лекциях 03–05 |

### Запустите четыре офлайн-практикума

Из корня репозитория с активированной виртуальной средой выполните следующие команды. Либо замените каждое `python` на `.\.venv\Scripts\python.exe` в Windows или на `.venv/bin/python` в macOS/Linux.

```bash
python -m pip install -r extras/lecture-02/requirements.txt
python extras/lecture-02/lab.py --output work/lecture-02-run

python -m pip install -r extras/lecture-03/requirements.txt
python extras/lecture-03/factor_lab.py --output work/lecture-03-run

python -m pip install -r extras/lecture-04/requirements.txt
python extras/lecture-04/evaluation_lab.py --output work/lecture-04-run

python -m pip install -r extras/lecture-05/requirements.txt
python extras/lecture-05/backtest_lab.py --output work/lecture-05-run
```

Для каждого практикума используйте отдельную папку вывода. Скрипты защищают посторонние непустые папки; перед изменением или повторным использованием пути прочитайте инструкции к лекции. Необязательные скрипты построения графиков и упражнение по сетевому сбору данных AkShare описаны в соответствующих папках лекций.

**Как интерпретировать результаты:** основные практикумы используют детерминированные **моделируемые учебные данные** и после установки зависимостей не требуют соединения с источником рыночных данных. Короткие выборки и условные издержки иллюстрируют методы; они не доказывают пригодность стратегии для инвестирования или её результаты вне обучающей выборки. В блокнотах могут загружаться реальные исторические цены. Некоторые демонстрации содержат сохранённые исторические данные; их элементы управления не загружают котировки в реальном времени.

## 7. Решение частых проблем

| Вопрос | Что делать |
| --- | --- |
| Почему на GitHub виден HTML-код? | Скачайте и откройте файл либо запустите локальный HTTP-сервер из раздела [«Начните здесь»](#start). |
| Почему Jupyter не находит пакет? | Установите пакет через `python -m pip` той же среды; проверьте выбранное ядро и перезапустите его после установки. |
| Почему не загрузились рыночные данные? | Проверьте сеть и ответ поставщика. Не считайте пустые данные успешным экспериментом. Продолжите обучение на офлайн-практикумах лекций. |
| Почему практикум отклонил папку вывода? | Выберите новую отдельную папку либо следуйте правилам лекции для повторного запуска в её собственную помеченную папку. |
| Переводит ли переключение языка блокноты? | Нет. Доступны десять руководств README; учебное содержание пока в основном на упрощённом китайском. |
| Как сообщить о проблеме? | [Создайте issue](https://github.com/ThreshoLdnnis/Quant-for-babies/issues), указав путь к файлу, команду, версию Python и сообщение об ошибке. Удалите из журналов токены и личные данные. |

Будем рады исправлениям, более понятным примерам и тщательно проверенным переводам. Сохраняйте одинаковые пути и команды во всех десяти руководствах; см. [заметки по поддержке переводов](README.md).
