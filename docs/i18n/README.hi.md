मात्रात्मक वित्त का पूर्व अनुभव आवश्यक नहीं है। Python की बुनियादी जानकारी नोटबुक के लिए उपयोगी है; आप पहले HTML पाठ पढ़ सकते हैं। हर पाठ में **पढ़ें → चलाएँ → एक धारणा बदलें → परिणाम समझाएँ** का क्रम अपनाएँ।

### HTML पाठ पढ़ें

**GitHub HTML का स्रोत कोड दिखाता है; रिपॉज़िटरी के फ़ाइल लिंक से पाठ चलना शुरू नहीं होता।** **Code → Download ZIP** से रिपॉज़िटरी डाउनलोड करें, उसे एक्सट्रैक्ट करें और अपने ब्राउज़र में कोई `extras/lecture-0N/index.html` फ़ाइल खोलें। पाँचों व्याख्यान पृष्ठ और सातों डेमो स्थानीय रूप से ऑफ़लाइन पढ़े जा सकते हैं। बाहरी संदर्भों और ऑनलाइन डेटा डाउनलोड के लिए इंटरनेट कनेक्शन आवश्यक है।

इसके बजाय, रिपॉज़िटरी के मूल फ़ोल्डर से यह कमांड भी चला सकते हैं:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

`http://127.0.0.1:8000/extras/lecture-01/` खोलें (अन्य व्याख्यानों के लिए `01` की जगह `02`–`05` लिखें)। macOS/Linux पर `python3` का उपयोग करें यदि `python` उपलब्ध न हो। सर्वर रोकने के लिए `Ctrl+C` दबाएँ।

व्याख्यान 01: आगे बढ़ने के लिए तीर वाली कुंजियों या स्पेस बार का उपयोग करें; वक्ता नोट्स के लिए `N`, अवलोकन के लिए `O` और पूर्ण स्क्रीन के लिए `F` दबाएँ।

## 2. नोटबुक के लिए अपना परिवेश तैयार करें

**Python 3.10+** का उपयोग करें; शुरुआत के लिए Python 3.12 एक उचित विकल्प है। क्लोन करने के लिए Git इंस्टॉल करें, या ZIP डाउनलोड करके एक्सट्रैक्ट करें। नीचे दिए गए कमांड टर्मिनल में चलाएँ। परिवेश के सीधे पथ इस्तेमाल करने से शेल में सक्रियण संबंधी समस्याओं से बचा जा सकता है।

<details>
<summary><strong>Windows · PowerShell</strong></summary>

```powershell
git clone https://github.com/ThreshoLdnnis/Quant-for-babies.git
cd Quant-for-babies
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

यदि आपने ZIP डाउनलोड किया है, तो एक्सट्रैक्ट की गई रिपॉज़िटरी के फ़ोल्डर में PowerShell खोलें और `python -m venv .venv` से शुरू करें।

</details>

<details>
<summary><strong>macOS / Linux · टर्मिनल</strong></summary>

```bash

cd Quant-for-babies
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

```

यदि आपने ZIP डाउनलोड किया है, तो एक्सट्रैक्ट की गई रिपॉज़िटरी के फ़ोल्डर में टर्मिनल खोलें और `python3 -m venv .venv` से शुरू करें।

</details>

### चार ऑफ़लाइन प्रयोग चलाएँ

रिपॉज़िटरी के मूल फ़ोल्डर से, अपना वर्चुअल परिवेश सक्रिय करके, निम्न कमांड चलाएँ। इसके बजाय आप हर `python` को Windows पर `.\.venv\Scripts\python.exe` या macOS/Linux पर `.venv/bin/python` से बदल सकते हैं।

```bash
python -m pip install -r extras/lecture-02/requirements.txt
python extras/lecture-02/lab.py --output work/lecture-02-run

python -m pip install -r extras/lecture-03/requirements.txt
python extras/lecture-03/factor_lab.py --output work/lecture-03-run

python -m pip install -r extras/lecture-04/requirements.txt
python extras/lecture-04/evaluation_lab.py --output work/lecture-04-run

python -m pip install -r extras/lecture-05/requirements.txt
python extras/lecture-05/backtest_lab.py --output work/lecture-05-run
```

हर प्रयोग के लिए अलग आउटपुट डायरेक्टरी उपयोग करें। स्क्रिप्ट उन असंबंधित डायरेक्टरियों की सुरक्षा करती हैं जो खाली नहीं हैं; आउटपुट पथ बदलने या दोबारा उपयोग करने से पहले व्याख्यान के निर्देश पढ़ें। वैकल्पिक प्लॉटिंग स्क्रिप्ट और नेटवर्क का उपयोग करने वाला AkShare डेटा संग्रह अभ्यास संबंधित व्याख्यान फ़ोल्डरों में समझाए गए हैं।

**परिणामों का अर्थ कैसे समझें:** मुख्य प्रयोग निश्चित नियमों से बने **सिम्युलेटेड शिक्षण डेटा** का उपयोग करते हैं और निर्भरताएँ इंस्टॉल होने के बाद उन्हें बाज़ार डेटा कनेक्शन की आवश्यकता नहीं होती। छोटे नमूने और काल्पनिक लागत विधियाँ समझाते हैं; वे निवेश योग्य रणनीति या औपचारिक आउट-ऑफ़-सैंपल प्रदर्शन स्थापित नहीं करते। नोटबुक में डेटा डाउनलोड वास्तविक ऐतिहासिक कीमतों का उपयोग कर सकते हैं। कुछ डेमो में ऐतिहासिक डेटा के स्नैपशॉट शामिल हैं; उनके नियंत्रण लाइव कीमतें नहीं लाते।
