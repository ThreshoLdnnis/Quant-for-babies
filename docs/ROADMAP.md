### 第三期 · 基于大语言模型的金融研究助手 \| 金融NLP与RAG项目

**LLM-Based Financial Research Assistant | Financial NLP and RAG Project**

#### 目标

构建一个面向金融研究的文档助手，让成员能够围绕公开或已获授权的年报、公告、研究材料提出问题，得到附带原文位置和证据的回答。通过完整项目掌握金融文本处理、信息抽取、检索增强生成（RAG）和回答质量评估，形成可复用的金融文档研究流程。

#### 主要内容

1. **金融语料与来源管理**：确定文档范围，记录公司、报告期、发布日期、获取时间、版本及使用范围；区分报告期与信息实际公开的时间。
2. **文档解析与金融 NLP**：处理正文、章节和表格，识别公司、指标、金额、币种与单位；保留页码、章节或原文片段定位，检查跨页表格及解析错误。
3. **检索数据管线**：设计文本切分、元数据过滤与索引，比较关键词、语义及组合检索方式；检查公司、日期和文档版本是否匹配问题。
4. **基于证据的回答**：将检索结果交给大语言模型，组织摘要、跨文档对比和指标解释；回答中给出出处，区分原文事实与分析推断，证据不足时说明无法确认。
5. **结构化提取与研究工作流**：尝试将财务指标、经营风险或事件整理成带来源的表格，保留数值、单位、时间及人工复核状态，支持回到原文检查。
6. **评估与错误分析**：建立固定问题集和人工核对答案，覆盖事实查询、数值提取、跨文档对比、版本冲突与无答案问题；比较基础搜索、直接模型回答和 RAG 方案，检查检索覆盖、事实一致性、引用准确性、拒答表现及响应成本。

#### 预期成果

- 一套可运行的金融文档检索与问答演示，支持查看回答及对应证据。
- 一份语料清单、文档字段字典和可复现的解析、切分、索引流程。
- 一套带核对依据的评估问题集，以及包含基线对照、错误案例和数值单位检查的评估报告。
- 一份项目说明与演示材料，说明适用问题、数据版本、运行方式和仍需人工复核的环节。

**验收重点**：抽查回答能定位到真实来源；指标的公司、期间和单位一致；没有证据或文档冲突时能如实报告。演示数据与真实文档明确区分，第三方可以按说明重建索引并复现评估。

### 第四期 · 适配市场机制的动态多因子配置 \| 量化研究

**Market-Regime-Aware Dynamic Multi-Factor Allocation | Quantitative Research**

#### 目标

在既有量价因子与静态多因子研究基础上，研究市场状态变化与因子表现之间的关系，并建立一套能够按当时可得信息调整因子权重的研究框架。重点检验动态配置是否带来可解释的收益、风险或稳定性改善，同时记录额外换手、费用和模型不确定性。

本期的“市场状态”需要用可观察的数据和明确规则定义，例如趋势、波动或流动性条件；这些状态划分属于研究假设，不能仅凭名称认定其揭示了市场运行机制。

#### 主要内容

1. **延续基础研究口径**：以20日动量、20日波动率和20日平均换手率为首版核心因子，固定价格、预处理、方向、股票池和执行协议，保留静态等权方案作为基线。
2. **市场状态定义与识别**：构建只使用当前及历史信息的状态指标，先建立简单规则基线，再按研究需要比较统计状态模型；状态阈值和模型拟合须遵守开发、验证和测试边界。
3. **分状态因子分析**：在不同状态下比较 Rank IC、ICIR、分组表现、相关性和样本覆盖，检查状态内样本数量及状态切换频率，保留不支持假设的结果。
4. **动态权重与约束**：制定状态到因子权重的映射、滚动更新规则及权重上下限，明确归一化、更新频率、平滑和换手控制。若使用滚动 IC，更新时只能利用截至该日已经成熟的未来收益标签。
5. **统一交易与公平对照**：将动态得分接入既有 Top N、目标权重、下一可交易时点执行、成交限制、现金和费用账本；在相同期间与协议下比较静态等权、简单动态规则、候选动态方案和预定参考组合。
6. **样本外与稳健性检验**：采用时间顺序的开发、验证、测试或滚动研究，检查成本敏感性、状态误判、切换滞后、权重集中和不同子区间；所有状态定义与调参尝试进入实验记录。

#### 预期成果

- 一份市场状态定义表、带时间戳的状态序列和分状态因子分析结果。
- 一套可复现的动态因子权重模块与配置，输出权重历史、约束检查和更新依据。
- 一组同口径的静态与动态对照实验，包含净值、回撤、换手、成本及样本外结果。
- 一份量化研究报告，解释何种状态和条件下观察到改善、何时失效，以及额外复杂度是否值得保留。

**验收重点**：任一时点的状态和权重都能追溯到当时可得的信息；未来标签跨界和成熟时间经过检查；动态方案与静态基线使用相同执行及费用条件。证据不足或未优于基线，也应作为完整研究结论交付。

### 第五期 · 基于机器学习的选股方法与可解释阿尔法研究

**Machine Learning-Based Equity Selection and Explainable Alpha Research**

#### 目标

将既有因子研究扩展为机器学习横截面选股研究，检验模型能否提供超出简单基线的样本外预测信息，并分析模型依赖哪些特征、何时稳定或失效。将预测评估、实际组合表现与模型解释连在一起，形成可复核的 Alpha 研究流程。

#### 主要内容

1. **研究目标与标签**：在实验前确定主要预测目标，例如未来收益或横截面收益排名，并固定预测期、股票池、样本区间和评价方法；未来标签仅用于训练与事后评价。
2. **特征与时点管理**：首版以量价信息和既有因子为主要特征，建立字段、窗口、可得时间和缺失处理记录；若扩展财务或其他数据，按实际发布日期与历史可得版本对齐。
3. **时间顺序训练与基线**：比较静态因子评分、简单线性模型与树模型等候选方案；模型参数、特征筛选和跨日期拟合的变换只使用对应开发数据，超参数选择不接触最终测试集。
4. **防止标签泄漏与过拟合**：检查特征回看、未来标签成熟时间、跨界标签及重叠窗口，采用预先声明的时间切分或滚动训练；记录尝试次数、失败方案、随机性及数据版本。
5. **从预测到组合**：同时评价 Rank IC、分组结果和目标相关的预测指标，再将模型分数接入统一的选股与执行流程；比较含费用的净值、回撤、换手、现金与集中度，保持与基线相同的交易假设。
6. **可解释性与增量信息**：分析全局特征重要性、个股局部归因、特征扰动与消融结果，检查相关特征对解释的影响及解释随时间的稳定性。模型归因描述预测依赖，不能直接当作因果关系或 Alpha 的证明。
7. **Alpha 来源与稳健性**：结合预定参考组合、风险暴露、行业或规模等分组讨论收益来源，检查成本和样本外表现；保留模型失效、解释不稳定及无法覆盖成本的情形。

#### 预期成果

- 一套带可得时间、标签定义和数据质量记录的可复现特征与标签管线。
- 一组固定切分和评价协议下的基线、模型、训练配置及样本外预测记录。
- 一份预测与组合联合评估结果包，包含 IC、分组、净值、回撤、成本和稳健性对照。
- 一份模型解释报告，展示总体特征依赖、代表性个股案例、消融结果和解释局限。
- 一套可重新运行的工程与实证报告，说明增量信息是否成立、依赖哪些条件及后续研究问题。

**验收重点**：能够重建训练、验证、测试边界及每条预测的模型版本；训练过程不使用测试信息；预测、解释和成交结果能够互相追溯。高预测分数、特征重要性或单段高收益，都需要与独立样本、风险及费用证据一起判断。

### 三期项目的衔接与共同交付

第三期可独立开展，并为后续研究提供文献整理与证据查找工具。第四期与第五期共享已验证的数据、因子定义、交易账本和基线；第四期重点研究状态与因子权重，第五期重点研究学习得到的股票评分及解释，便于分别识别新增方法的贡献。

各期拟按“冻结问题与数据协议 → 建立可运行基线 → 完成核心方法 → 独立评估与错误分析 → 整理工程、报告和答辩”推进，启动时再确定具体排程。

共同交付包括：

- **GitHub 工程**：入口、依赖、参数、数据说明和运行命令清楚，演示与实证状态明确。
- **可复现实验**：保存数据版本、配置、代码版本、评估区间、基线及全部预定对照结果。
- **研究报告**：目标、方法、证据、负结果与局限相互对应，图表能够追溯到输入和输出。
- **个人答辩**：每位成员能够独立解释一个核心方法、一次评估、一项错误或偏差，以及一张结果图。

真实数据的使用范围和发布方式在启动时核定；模拟数据须明确标注。规划不预设模型一定优于基线，也不承诺策略收益。前期[五讲基础课程](../README.md#番外期--第二期课前培训)提供数据、因子、检验和回测的共同基础，正式项目仍需按各期问题补充数据与独立证据。
