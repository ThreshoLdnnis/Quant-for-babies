## 连续数据与执行协议

- 原样引用第三讲的8只虚构股票、80个模拟工作日、原始价/调整收盘价、三个量价因子、MAD、横截面Z-score与MOM+/VOL−/TURN−方向。639行原数据补为640行网格，3个缺失价格保留。不是交易所日历，没有真实公司行为；仅在本模拟中`close_raw==adj_close`。
- 静态因子权重各1/3，三因子共同有效才能进入候选。四种选股策略Top3，等权目标；代码升序作为预先声明的截点同分规则。正式Top10需要更大的研究股票池。
- 2024-01-31、02-29、03-29收盘形成信号，次模拟日02-01、03-01、04-01开盘尝试执行。04-22为未完成月份的终点审计快照，不是月末调仓，也没有越界成交。
- 新增开盘报价=前一原始收盘×`(1+0.001*sin(0.37*日期索引+股票索引))`，明确为模拟，不使用当天或未来收盘。前收盘缺失则报价缺失，不补可交易价格。
- 初始100万元、教学整手100股、只做多，先卖旧股再按代码顺序买入；现金和费用限制可买数量。未成交单当次失效，下一期重新形成目标；未重试追价，不模拟排队或部分流动性撮合。
- 人为新增开盘竞价不可用、买入阻断、卖出阻断均为模拟情景，并非真实涨跌停判断。原数据既有全天停牌状态保留。收盘缺价只在账本使用上次可得估值并标记stale，不回填因子或未来标签。
- 参考组合为预先声明的8股等权模拟组合，使用相同调仓、执行、成本和资金；比Top3更分散，不能称作真实市场指数或风险调整Alpha。

## 假设成本与统计口径

| 情景 | 买卖每边佣金 | 卖出附加税费 | 每边滑点 |
| --- | --- | --- | --- |
| zero | 0bp | 0bp | 0bp |
| base | 3bp | 5bp | 5bp |
| high | 6bp | 10bp | 10bp |

全部是教学假设，不是当前或历史券商/法定费率。无最低佣金、冲击和容量模型。滑点通过实际成交价进入现金，不再重复扣现金；成本汇总将滑点单列以便解释。

实际双边换手字段为`Σ(|成交股数|×开盘参考价)/调仓前开盘权益`，不除以2；不是目标权重变化或单边换手。每档费用完整独立运行，整手和现金约束可使实际成交路径改变。

五种方案×三档成本=15套账户。日净收益由相邻账户权益计算，保留初始现金预热，统计共80期。夏普日无风险利率0，样本标准差ddof=1，按sqrt252近似换算；几何年化为终点净值的252/80次幂减1。短模拟的高夏普不是真实有效性证据。最大回撤包含初始净值1，以非正数报告。

## 固定模拟结果与边界

多因子base：3个执行日、8笔实际成交、累计收益11.5809557%、最大回撤−2.3709049%；总假设成本2310.7415656元，包含佣金731.3115608、卖出税费360.8256993、滑点1218.6043055。这些数值只能核对程序，不能据此选真实策略。

实际触发开盘不可用、买入受阻、卖出受阻、现金不足整手、现金限制部分买入，以及持仓缺价的陈旧估值。四种选股策略都用同日共同因子候选；参考组合采用更广的8股池，差异明确披露。

第四讲的严格时间切分仍为开发`[0,40)`、验证`[40,60)`、测试`[60,80)`，三段成熟共同X–Y配对均0。第五讲全样本账户演示不补足正式样本外证据；真实实证需更长历史、历史成员、公司行为、交易状态和真实费用。
