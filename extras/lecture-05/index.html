01 / From scores to an account

因子表之后，为什么还需要一层交易账本？

因子表的一行告诉我们：某只股票在某个时点具有怎样的特征。它没有告诉我们买了多少股、是否买得进、钱从哪里来、交易后还剩多少现金。把评分直接乘当天收益，会跳过这些问题，也可能把收盘后才知道的信息，放进已经发生的交易。

  1. 预处理与合成同日去极值、标准化、方向统一。
  2. 排名与目标Top N名单、等权目标及时间戳。
  3. 执行与记账下一开盘、阻断、股数、现金、费用。
  4. 评价与报告净值、风险、对照、实验记录。
层次输入输出不能混淆
信号当时可得的历史数据因子得分、排名高得分不是成交回报。
目标组合排名与组合规则目标名单、目标权重计划持有不代表实际持有。
交易账户前持仓、现金、报价与限制成交股数、费用、实际持仓不能假定所有委托都成交。
研究结果账户每日权益与对照净值、回撤、指标、结论模拟表现不能冒充实证。

最小闭环不是把每个环节都做得复杂，而是保证各层含义一致。一份几十行的理想化收益演算，可以教公式；本讲配套脚本再用明确的股数与现金，把这些公式落到可检查的模拟账本。

02 / Static factor combination

三种特征，怎样变成一个可比较的总分？

第三讲的MOM20、VOL20、TURN20分别描述过去的价格趋势、日收益离散程度和平均交易活跃度。即使都写成小数，它们的尺度也不同。直接相加会让数值波动较大的指标主导结果，未必符合我们希望的权重。

本项目先沿用同一日期、同一研究股票池的MAD裁剪与横截面Z-score，再乘预先固定的方向。本课使用MOM正向、VOL负向、TURN负向作为教学假设。负向意味着“原指标较小，对应的方向得分较高”，不意味着已经证明低波动或低换手在真实市场有效。

Si,t = ⅓[dMZMOM,i,t + dVZVOL,i,t + dTZTURN,i,t]
dM=+1，dV=−1，dT=−1Z为同日预处理后的标准化因子；S为无量纲合成得分。等权是因子权重各1/3，尚不是股票资金权重。

“静态”表示合成规则和因子权重预先固定，不随本次回测表现动态变化。每天重新计算Z-score后，股票得分当然会变化；这不等于采用了动态因子配置。方向也不根据第四讲模拟IC的正负临时重选。

import pandas as pd

# 同一模拟截面的教学输入；此处只演示Z-score与固定方向合成
sample = pd.DataFrame({
    "symbol": ["A", "B", "C", "D"],
    "mom20": [0.12, 0.04, -0.06, -0.10],
    "vol20": [0.02, 0.01, 0.06, 0.04],
    "turn20": [0.01, 0.02, 0.04, 0.03],
})
for name in ["mom20", "vol20", "turn20"]:
    s = sample[name]
    sample[name + "_z"] = (s - s.mean()) / s.std(ddof=0)
sample["score"] = (sample["mom20_z"] - sample["vol20_z"] - sample["turn20_z"]) / 3
print(sample[["symbol", "score"]].round(6))
# 仅为合成公式独立例子；完整实验还沿用第三讲MAD与有效样本检查

前三列是独立模拟的教学数值，示例先逐列减同日均值、除以总体标准差，得到真正的Z值；此处四只股票没有常量列，只为手算展示，不替代第三讲完整预处理。两个减号来自预先约定的负方向；除以3让三个因子各占1/3。完整程序直接读取第三讲方向得分再取均值，避免对VOL/TURN重复乘负号。

有一项缺失，可以临时改成另外两项各一半吗？

可以研究这种规则，但必须提前声明，因为它改变了每天的因子构成。本课要求三个方向得分共同有限，缺一个就不生成合成分；不将缺失填0，也不临时重分配因子权重。若有效候选不足Top N，按预先规则保留状态，不扩大股票池凑数。

03 / Rank first, select second

Top N只是一条明确的选股规则

有了合成分，把同一日期的候选股票按得分从高到低排序，再取前N只。N是运行前的参数，不应看完曲线后从1试到50，只展示最漂亮的一次。原项目可预先采用Top 10；本课只有8只虚构股票，因此演示固定Top 3，不冒称已经实现10股组合。

排序前要检查股票池和样本。研究股票池应使用当时可获得的历史成员，而不是今天仍上市的股票清单。教学实验的8股从起点就预先声明；三因子共同有效条件进一步决定当期候选。这样的模拟无法检验退市与历史成员变化的真实影响。

import pandas as pd

scores = pd.DataFrame({"symbol": list("ABCDEFGHIJ"),
                       "score": [0.8, -0.1, 0.6, 0.4, 0.2, 0.9, -0.5, 0.1, 0.3, 0.6]})
ranked = scores.dropna(subset=["score"]).sort_values(
    ["score", "symbol"], ascending=[False, True], kind="stable")
chosen = ranked.head(3).copy()
chosen["target_weight"] = 1 / len(chosen)
print(chosen)
# 预先约定同分按symbol升序；选F、A、C，每只目标权重1/3

dropna只清掉无法排序的分数，真实入口还要处理无穷值。排序先看得分，再按事先声明的代码次序处理截点同分，保证重跑一致。这种Top N裁决是组合约定，并未改变第四讲Spearman的平均秩或把qcut并列强拆成虚假预测差异。head(3)给出目标名单；等权只记录计划，交易引擎稍后才尝试实现。

04 / Targets versus actual holdings

等权的是调仓目标，实际权重会漂移

假设账户权益100万元，Top3目标权重各1/3，理想分配是每只约33.33万元。即使没有费用，也很难恰好实现：股票按股数成交、委托有整手约束，某只股票可能买不进，卖单也可能无法执行。留在账户的现金必须保留在资产负债恒等式里。

目标：wi* = 1/N
实际：wi,t = qi,tVi,t/Et
Et = Casht + Σiqi,tVi,tq为实际股数，V为账面估值报价，E为账户权益。股票权重加现金权重应为1。

调仓完成后也不会每天保持等权。若A和B起初各50%，之后A上涨10%、B不变，那么A权重变成55/105≈52.38%，B约47.62%。没有交易时，这种变化是价格驱动的漂移。每天强行写回50%，实际上暗含了每天再平衡及额外成本。

initial_a, initial_b = 50.0, 50.0
value_a = initial_a * 1.10
value_b = initial_b * 1.00
equity = value_a + value_b
print(round(value_a / equity, 6), round(value_b / equity, 6))
# 0.52381、0.47619；没有再平衡就不是每天50%/50%

用初始资金乘各自价格变化，得到真实持仓市值，再除以总权益；不是重新将初始资金平均分配。这一行分母是两只股票变化后的价值总和。完整实验还把现金计入分母，输出调仓前、目标、执行后三套权重。

05 / Causality before returns

信号时间、交易时间、收益期间，必须分别写清

月末最后一个交易日收盘之后，我们才拿到当天完整收盘价、成交量和换手率，进而计算因子。若假定已经按同一收盘价买入，就把“看到答案之后的决定”放进了过去。给权重简单加一行shift(1)也不自动保证正确，还要明确下一时点用什么价格和哪些收益。

T日收盘形成信号

原始输入、因子、方向、Top N名单带时间戳。

T+1开盘前后尝试执行

先用旧持仓和现金承接隔夜变化，再按开盘报价与规则交易。

T+1收盘估值记账

新持仓只承担成交后价格变化，费用已从现金扣除。

下一调仓重复流程

期间股数不变，权重自然漂移；失败单按明确政策处理。

开盘执行时，谁获得隔夜收益？

昨天已经持有的股票，会从昨天收盘走到今天开盘；今天开盘才买入的新股票，不能获得这段已经发生的隔夜收益。本课引擎用股数、现金和报价逐步计算，因此不会把新目标权重乘到整段“前收盘→今收盘”收益上。若采用别的执行方式，例如下一收盘，收益归属也必须相应改变。

步骤允许使用的信息常见错误
形成T日信号截至T日收盘可得的数据用T+20收益调方向。
T+1开盘执行已冻结信号、开盘报价和可得状态先看T+1收盘再决定开盘买谁。
T+1收盘估值实际成交后股数与收盘估值新股数获得买入前的隔夜涨幅。
末日信号信号可保存，未来执行日尚不存在越出数据末日编造一笔成交。

本实验在已完成月份的模拟月末索引21、42、63形成信号，分别在22、43、64执行；末尾79位于未完成月份，仅保存终点审计快照并记录“无后续执行日期”，不把它称作真实月末调仓。日期索引来自模拟工作日网格，不等于A股交易所月末。真实项目应使用经核对的交易日历。可参考 pandas的shift定义；行移位本身不能替代执行模型。

06 / A return must name its interval

组合收益，先明确权重何时已经生效

最容易手算的情形，是某个收益期间开始前权重已经生效，期间没有买卖，也没有公司行为。若个股收益为R，现金收益暂设为0，组合毛收益就是开始时各权重乘各自收益的加总。发生交易时还要计算实际费用与成交时点，不能把公式当作时间对齐的替代。

Rp,tgross = Σiwi,t−1Ri,t
Rp,tnet = Rp,tgross − Ctw必须是这段收益发生前实际生效的权重；C为按同一权益分母表达的总成本。开盘中途调仓时，要拆开收益区间或直接用账户权益变化。
import pandas as pd

# 纯手算模拟：期间开始前已经持有50%/50%，期间没有再交易
weights = pd.Series({"A": 0.5, "B": 0.5})
asset_returns = pd.Series({"A": 0.02, "B": -0.01})
gross = (weights * asset_returns).sum()
cost_fraction = 0.002  # 假设总成本占同一初始权益0.20%
net = gross - cost_fraction
print(f"gross={gross:.2%}, net={net:.2%}")
# gross=0.50%, net=0.30%

代码用股票标签对齐两列，再做逐项乘法和求和；这里两股都存在，不能把真实数据中的缺失收益默认为0。0.002是本次期间总成本相对初始权益的假设，不是每边佣金。最后减成本只对这一简化口径成立。完整账户的净收益直接用相邻收盘权益之比计算，费用与滑点已通过现金和成交价进入账户。

调仓日怎样得到可信的日收益？

先保存昨天的收盘权益Et−1，今天用昨天的股数跨过隔夜，按今天开盘规则交易，随后用实际收盘报价估值，得到Et。日净收益为Et/Et−1−1。只要没有外部出入金，账户恒等式会将隔夜、日内、交易费用和现金一起反映出来。真实有出入金、分红或公司行为时，还需专门的现金流和股数调整。

07 / Trading consumes resources

换手率和成本，都要写清分子、分母与单边双边

“成本20个基点”并不完整。它可能指每边费率，也可能是本期已经汇总的账户成本；“换手率100%”也可能只数买入，或同时数买卖。1个基点（bp）=0.01%=0.0001。没有这些约定，两个回测即使画出相近曲线，也未必可比较。

交易金额B = Σ买入股数×开盘参考价
交易金额S = Σ卖出股数×开盘参考价
双边成交强度 = (B+S) / 调仓前开盘权益一些文献将双边金额除以2，或报告单边/买入换手。本课会直接给出成交金额与完整字段定义，不把不同口径混称。

如果把一组旧股票全卖掉，再把资金买入另一组，双边交易额可能接近权益的两倍；若使用半L1口径，数值可能接近1。目标权重的变化量只是计划，遇到失败交易后，应按实际成交统计成本和换手。

三类现金影响，分开记

佣金

按实际买卖金额分别计算。真实最小收费、费率和渠道不同，不能用一个常数代表所有账户。

卖出相关税费

教学引擎作为单独的卖出成本参数。真实研究按历史日期和适用规则计量。

滑点

买入价比参考报价略高、卖出价略低。已体现在成交价中，不再从收益重复扣同一项。

本课的zero/base/high均为假设成本情景，具体参数由脚本输出。它们不是当前券商报价，也不声称复刻2024年的法定费率。0成本只帮助隔离机制，不代表现实能免费交易；高成本用于敏感性分析，不用于挑选最漂亮的一档结论。

手算：毛收益固定时，成本怎样侵蚀结果？

独立假设 · 不改变完整实验
毛收益+0.50%
假设总成本0.20%
本期净收益+0.30%

此滑块只算净收益=0.50%−总成本，不能拿它按比例缩放完整账户净值。真实重新运行不同费用，整手和现金约束可能改变成交股数与后续持仓。

08 / A market is more than a price table

A股约束：有价格，不代表想买多少都能成交

真实交易规则随证券类别、板块、日期和状态变化。普通A股股票的当日买入通常不能当日卖出；停牌、涨跌幅限制、委托与数量规则等也会影响执行。不能把一条经验百分比套在所有历史股票上，更不能把今天规则倒放到整个历史。可查 上交所2026修订通知 与 深交所2026规则PDF；研究实现应保存历史适用版本。

缺失收盘价，估值和特征要分开

账本为了连续显示权益，可能暂沿用该股上一可用估值，并明确标记“陈旧估值”；这不表示当天真的可以按旧价成交，也不表示收益真实为0。缺失必须进入估值审计，真实研究还要调查停牌、漏采、公司行为与退市。不能将账本里的估值补齐，反写到第三讲因子输入或第四讲未来标签。

复权研究价格，不可以直接当现金成交价

真实研究通常用一致的调整价格计算历史特征；执行按原始报价、实际股数与公司行为记账。现金分红、送转和拆合股会改变现金或股数，不能将前复权价乘真实股数当账户市值。本教学模拟没有这些公司行为，第三讲已声明close_raw=adj_close；这只是模拟条件，不是对真实A股的通用等式。

失败单要有政策。

本课冻结当次目标后，失败委托按本次未成交记录，不在未来看到更好价格后偷偷补成交；下一月按新的信息重新形成目标。若采用每日重试或部分成交，应在运行前另写规则，并重新核对时间与成本。

09 / Equity first, NAV second

净值来自账户权益，最大回撤要包含初始高点

以初始资金E0为基准，净值NAVt=Et/E0。若期间无外部出入金，它也等于每日净收益的连乘。把每日收益直接相加只是粗略近似；把第四讲重叠20期未来收益逐日连乘，则在收益期间上已经错位。

NAV0=1
NAVt = NAVt−1(1+Rp,tnet)
累计收益 = NAVT−1
DDt = NAVt/max(1,NAV1,…,NAVt)−1本课最大回撤MDD=min(DD)，以非正数报告；也可以报告其正的绝对幅度，但必须注明口径。初始净值1参与历史峰值。
import pandas as pd

net_returns = pd.Series([0.10, -0.10], dtype="float64")
nav = (1 + net_returns).cumprod()
peak = nav.cummax().clip(lower=1.0)  # 初始净值1也是候选高点
drawdown = nav / peak - 1
print(nav.round(6).tolist())        # [1.1, 0.99]
print(round(float(drawdown.min()), 6))  # -0.1
loss_first = pd.Series([0.9])
print((loss_first / loss_first.cummax().clip(lower=1.0) - 1).iloc[0])
# 首期直接跌到0.9，应记-10%回撤，不能被当成新起点而记0

第一行连乘得到实际路径，+10%后−10%的终点是0.99，累计收益−1%。cummax保存此前高点，clip(lower=1)把初始资金基准也纳入。回撤问的是“相对自己此前最好时点跌了多少”，不同于当日收益或相对市场基准的落后。

最大回撤是观察区间内的历史路径统计，不是未来最大损失上限。净值越过旧峰值才完成回撤修复；区间结束仍未修复时，恢复期应写“未恢复”，不编造未来恢复日期。

10 / Returns need a risk language

夏普、波动率与回撤，各自在回答什么？

累计收益告诉我们这段区间资金增长多少，波动率描述日收益的离散程度，夏普把平均超额日收益与这种离散程度联系起来，回撤描述沿着净值路径从高点下跌的幅度。它们不能互相替代；收益较高而回撤更深、换手更高的方案，需要把代价一起展示。

年化波动率 ≈ √252 · s(Rp,t)
Sharpe ≈ √252 · mean(Rp,t−Rf,t) / s(Rp,t−Rf,t)
几何年化收益 = (NAVT/NAV0)252/T − 1使用日净收益，样本标准差ddof=1。252是常用近似年度交易日数；时间缩放依赖相应统计条件，尤其不应忽视自相关。短样本的年化只是换算，不是可持续增长承诺。

无风险利率要与日收益同频。如果采用年有效利率rf,annual，在声明252日假设下可换算rf,daily=(1+rf,annual)1/252−1，不能直接每天减去年利率。本模拟将现金收益和日无风险利率均设为0，是教学假设。比率与时间聚合条件可读 Sharpe原文；短样本和序列相关的提醒见 Lo（2002）公开摘要。

import math
import pandas as pd

def describe_daily_returns(values, rf_daily=0.0):
    r = pd.Series(values, dtype="float64")
    if r.empty or r.isna().any() or not r.map(math.isfinite).all() or (r <= -1).any():
        raise ValueError("需完整、有限且大于-100%的日收益")
    excess = r - rf_daily
    sd = r.std(ddof=1) if len(r) >= 2 else float("nan")
    excess_sd = excess.std(ddof=1) if len(r) >= 2 and excess.nunique() > 1 else float("nan")
    sharpe = math.sqrt(252) * excess.mean() / excess_sd if math.isfinite(excess_sd) and excess_sd > 0 else float("nan")
    terminal = float((1 + r).prod())
    return {"total_return": terminal - 1, "annual_return": terminal ** (252 / len(r)) - 1,
            "annual_vol": math.sqrt(252) * sd, "sharpe": sharpe}

print(describe_daily_returns([0.01, -0.005, 0.002, 0.0]))
print(describe_daily_returns([0.0, 0.0])["sharpe"])  # 常量序列：缺失，不是无限优秀

输入检查不让缺失悄悄改变样本期，也避免把无效价格变成收益。标准差采用样本口径，夏普的分子和分母都来自同频超额收益；常量或不足两期时保留不可定义状态。几何年化使用真实连乘终点与有效观察期数；这四期的例子只是检查公式，不适合经济推断。完整脚本另外报告样本期间、初始现金阶段和实际调仓次数。

指标可以读出什么不能直接读出什么
年化收益按声明频率对区间几何增长换算。未来每年能赚这么多。

再多一步：为什么新目标不能赚到隔夜涨幅？

昨天收盘旧持仓A为100股、每股10元，另有现金1000元；账户权益2000元。今天A开盘11元，旧持仓先上涨100元，开盘前权益2100元。此时卖A换买B，不会抹去旧持仓已经产生的收益，也不能让新买入B获得它的昨日收盘到今日开盘变化。先估值、再交易，才知道今天的现金和股数从哪里来。

shares_a, cash = 100, 1000.0
yesterday_close_a, today_open_a = 10.0, 11.0
yesterday_equity = cash + shares_a * yesterday_close_a
before_trade_equity = cash + shares_a * today_open_a
overnight_pnl = before_trade_equity - yesterday_equity
print(yesterday_equity, before_trade_equity, overnight_pnl)
# 2000、2100、100；这是旧持仓跨过隔夜的损益

同一股数分别乘两个时点报价；现金在本例隔夜不生息。两项权益的差额来自旧持仓，新的买卖尚未发生。完整脚本按实际成交价、税费、手数和阻断继续处理，不能把这个小例子扩写成一份省略现金的“真实交易回测”。

13 / RESEARCH DESIGN / TIME-ORDERED EVIDENCE

先冻结规则，再让未使用的数据回答问题

一条历史净值曲线既可以是检验结果，也可能是反复挑选的产物。若研究者看完所有日期后，才决定动量方向、选股数量、调仓频率和费用假设，最后的高收益已经包含了选择这些规则时得到的帮助。程序没有报错，并不能消除这类研究偏差。

本课固定第三讲的三种因子：20期动量、20期日收益样本标准差、20期平均换手率；方向分别为MOM正、VOL负、TURN负。预处理仍按同日截面完成，静态合成使用三个方向得分各三分之一。它们是预先声明的教学规则，不根据本次模拟回测的优劣重新拟合。正式研究还应冻结历史股票池、调仓日、Top N、成交价格、失败订单政策、费用、估值与绩效口径。

时间段用途何时失去“未使用”的身份？
开发检查计算，提出有限候选，记录成功与失败。本来就用于开发，不应再当作独立证明。
验证比较开发出的候选，决定保留或拒绝方案。只要参与参数、方向或策略选择，就应承认它已提供选择信息。
最终测试关键规则冻结后，评价未用于选择的一段历史。看结果后修改规则，再用同一段证明成功时，它已经成为开发资料。

第四讲的样本不足，不能在第五讲被悄悄抹掉

贯穿课程的数据只有8只虚构股票、80个模拟工作日。第四讲预先划定开发[0,40)、验证[40,60)、测试[60,80)，同时要求未来20期标签在所属段内成熟。按这一严格规则，三段共同可用的因子—标签配对都为0：开发段早期因子尚未预热，后期标签跨界；验证和测试各20个价格位置，放不下完整20期间隔。

第五讲可以用全样本运行交易会计演示，因为“能否按已知信号记账”和“是否已有充分独立证据”是不同问题。能够生成净值，不表示已经完成三阶段样本外验证。报告应明确写“全样本模拟方法演示，正式样本外证据不足”，并在真实项目中补充更长历史，而不是移动切分线、缩短标签或重选股票来制造一个可用结论。

标签终点与执行日期都要检查。

开发截止时尚未实现的未来收益，不能用于当时选择方向。因子日收盘后形成的信号，也不能被写成已经按当日收盘成交。验证日使用此前已知的历史价格则是正常的特征回看，不必因为这些价格位于开发段而全部丢弃。

最终测试表现不好时，研究仍然有产出

可以报告方向不稳定、成本侵蚀明显、组合集中或样本太少。新想法可以继续提出，但要保留原结果，声明哪些资料已经看过，再设计新的未使用检验。独立测试的作用是限制自我说服，不能保证策略通过。

14 / ROBUSTNESS / KEEP THE COMPARISON FAIR

稳健性：改变合理假设后，结论还能站住吗？

一组参数下的结果只是起点。稳健性检验应围绕事先可以说明理由的变化展开，并保留完整结果。这里的目标是识别策略依赖什么条件，不是从更多试验里挑出更漂亮的一条线。正式测试使用过多少次、失败过哪些版本，都应进入实验记录。

对照实验保持一致观察什么解释边界
零费用／基础／较高费用因子、方向、信号日、选股与执行规则。净值、累计成本、成交量、现金与排名是否变化。教学费率是假设，不是当前券商收费表。重新成交时，整手与资金约束可能改变实际持仓。
不同预先规定子区间策略定义与统计口径。优势是否仅集中于少数日期或一段行情。看到结果后挑开始和结束日期，会引入新的选择偏差。
不同历史股票池每个历史时点可得的成员信息。结果是否依赖今天仍存在、仍活跃的公司。不能用今天的成分股名单倒推全部历史，也不能默默删除退市样本。
成交限制与估值政策信号时间、订单规则及价格来源。未成交、停牌、现金滞留和估值陈旧的影响。可计算价格不等于一定可以成交；缺失不能被当作免费离场。
单因子／静态多因子／参考组合初始资金、可交易范围、执行时点、成本及评价区间。收益、风险、回撤、换手与集中度的完整差异。多因子并不保证优于每一个单因子；虚构参考组合不是真实市场指数。

费用敏感性，要比较同一套研究协议

把买入佣金、卖出佣金、卖出税费和滑点分别写成参数，避免把一次调仓的买卖成本只算一边。零费用场景帮助理解信号与交易路径；基础与较高费用场景帮助观察可投资性的脆弱程度。所有场景应完整重新运行，记录实际成交与费用。不要只把净值末端减一个固定百分比，就称作准确的成本回测。

费用上升一般会增加交易负担，但在有现金和整手约束的重新模拟中，可买股数、余留现金与后续持仓也可能变化，因此不能预设每一天的曲线都必须严格按费用排序。若要在完全相同成交路径上比较纯费用负担，应另行声明这是固定成交路径的反事实计算，不能和重新执行订单的结果混称。

四种常见错误，对应四类检查

前视偏差：当日收盘信号却赚到同日收盘前的涨幅，或使用未来标签挑方向。检查每一笔订单的信号日、执行日和收益区间。幸存者偏差：只保留今天存在的股票。检查历史成员、退市与异常状态。选择偏差：尝试很多窗口却只展示最优结果。保留尝试清单，并隔离最终测试。会计不一致：目标权重直接冒充实际权重，费用扣了两次或现金变负。逐日核对持股、估值、现金、成本与净资产。

模拟限制案例，只能验证处理流程。

人为设置的停牌、买入受阻或卖出受阻，可以检查订单是否被错误地假定成交；它们不能证明程序已经重建真实A股涨跌停排队、流动性与市场冲击。真实研究需要可追溯的历史交易状态和更明确的执行模型。

练习1：两只股票的涨跌，怎样成为组合净收益？

某期间开始前已经生效的股票权重均为50%；A收益为+2%，B为−1%。假设该期间交易总成本占期初组合净资产0.20%，求毛收益、净收益和100万元资金的期末净资产。这里先忽略期间内其他资金流与收益时点细分。

展开手算、独立代码与解释
Rgross = 0.5×2% + 0.5×(−1%) = 0.50%
Rnet = 0.50% − 0.20% = 0.30%
Vend = 1,000,000×1.003 = 1,003,000元
import math

weights = [0.5, 0.5]                                  # 1. 期间开始前生效
returns = [0.02, -0.01]
gross = sum(w * r for w, r in zip(weights, returns))   # 2. 加权毛收益
cost_ratio = 0.002                                    # 3. 已按期初资产折算
net = gross - cost_ratio
end_value = 1_000_000 * (1 + net)                      # 4. 期末资产
assert math.isclose(net, 0.003, abs_tol=1e-12)
print(f"毛收益 {gross:.2%}，净收益 {net:.2%}，资产 {end_value:.0f}元")

第1步固定已经生效的权重；第2步才把它们与同一期间收益相乘；第3步说明0.20%已经是组合层面的成本比例，不能再按两只股票重复扣；第4步用净收益更新资产。预期输出为毛收益0.50%、净收益0.30%、资产1003000元。完整引擎会按实际成交与现金记账，不能把这个简化例子当成执行模型。

练习2：净值回到0.99，最大回撤是1%还是10%？

含初始时点的净值为1.00、1.10、0.99。求累计收益与最大回撤。再考虑另一条路径：初始1.00，首期0.90，第二期0.99；为什么不能把初始1.00丢掉后计算历史高点？

展开净值、高点与独立代码

第一条路径累计收益为−1%，但从历史高点1.10跌至0.99，回撤为−10%，因此最大回撤为−10%。累计收益比较起点与终点，回撤比较每个时点与此前高点，它们回答不同问题。第二条路径也曾从初始1.00跌到0.90；若只对0.90、0.99求累计最高值，会错误地漏掉第一次−10%的损失。

import pandas as pd

nav = pd.Series([1.00, 1.10, 0.99], dtype="float64")   # 1. 保留初始时点
peak = nav.cummax()                                   # 2. 当时以前的最高值
drawdown = nav / peak - 1                             # 3. 各时点回撤
total_return = nav.iloc[-1] / nav.iloc[0] - 1
print(f"累计收益 {total_return:.2%}，最大回撤 {drawdown.min():.2%}")

first_loss = pd.Series([1.00, 0.90, 0.99])             # 4. 首期就下跌
assert abs((first_loss / first_loss.cummax() - 1).min() + 0.10) < 1e-12
# 预期：累计收益 -1.00%，最大回撤 -10.00%

第1步把初始净值放进序列；第2步维护截至当前的峰值，不能使用未来最高点；第3步计算相对峰值的跌幅，再取最小值；第4步单独检查首期损失是否被遗漏。这里报告带负号的最大回撤；若报告正的损失幅度，应明确改为其绝对值，不能混用。

练习3：收盘信号，为什么不能赚到已经发生的当天涨幅？

代码在T日收盘后选出Top 3，随后直接用T日目标权重乘以“T−1收盘至T收盘收益”，并声称按T收盘买入。指出信息与执行的错误，画出合理时间线。如果T+1开盘买入受阻，应如何处理？

展开时间边界与未成交答案

T日收盘价参与信号时，整段T−1至T的收益已经发生；把刚产生的目标权重乘上去，等于提前知道答案并提前持有。合理顺序为T收盘形成并冻结目标，T+1按预定规则尝试执行，之后只计算实际持仓承担的价格变化。下一开盘执行时，还应区分旧持仓承担的隔夜变化与新成交后的变化；把权重简单整体移一行，未必足以模拟这一细节。

买入受阻时不能假定成交，也不能事后挑更便宜的价格补单。按预先写好的订单政策保留现金或处理订单，并保存原因、执行日期与实际成交量。后续收益依实际持仓和现金计算，目标权重保留用于比较偏离。

练习4：等权持有以后，每天仍然是50%／50%吗？

A与B最初各持有50元；随后A上涨10%，B下跌10%，没有交易和费用。求组合收益与新的实际权重。如果下一次调仓希望恢复等权，按此时价格需要各调整多少元？

展开漂移权重与调仓金额

两只股票市值变为55元与45元，资产总额仍100元，因此组合这一期间毛收益为0%，实际权重变为55%与45%。恢复各50元目标，需要卖出5元A、买入5元B（暂不考虑现金、费用与整手约束）。等权是调仓时设定的目标；价格变化后权重会漂移，不会自动每天恢复。

若没有记录对应交易，却每天都用固定50%／50%权重计算，就隐含了每日再平衡，和月度调仓不是同一个策略。完整回测需要在两次调仓之间持有真实股数，让市值与现金共同决定权重；整手和失败订单又可能让实际权重从成交当天起就偏离目标。

练习5：一个夏普数值，能直接与任何其他夏普比较吗？

甲用日收益和日无风险收益计算后乘√252；乙把同一条日收益的均值与标准差代入却乘√12；丙将年无风险利率2%直接从每日收益中减去；丁把80日模拟曲线的高年化夏普当作未来一年保证。分别指出问题。

展开频率、利率与推断边界

甲至少对齐了输入频率与常见年度日数近似，但仍须声明样本标准差、无风险口径、交易日数近似和时间相关性；平方根缩放需要适当条件。乙的√12对应月度等频观察的常用近似，不能直接用于日收益。丙把年利率和日收益混用，需先按预定口径转换，例如固定有效年率假设下日收益为(1+0.02)**(1/252)-1。丁把短样本描述误读成未来承诺，忽略模拟路径、估计误差与策略筛选。

五讲之后，交付一条能被检查的研究链

第一讲建立“数据—因子—检验—策略—回测—报告”的全局框架；第二讲让行情成为有字段、键与质量记录的数据；第三讲把历史信息变成定义清楚的因子；第四讲评价因子与未来收益的关系；第五讲把固定得分接到持仓、成交、费用和净资产，再把证据写入报告。每一步的输出，都应该是下一步可追溯的输入。

现在应能回答六个具体问题：因子何时可得？得分怎样形成目标股票？订单何时真正成交？资金和持仓怎样变化？净值与风险怎样计算？这些观察足以支持多强的结论？如果其中任何一个问题只能靠“程序就是这样写的”解释，还需要回到相应章节核对定义与时点。

把规则写清楚

保留公式、价格、样本、窗口、方向与执行协议，让研究对象稳定下来。

把账算完整

目标与实际分开，现金与费用入账，失败成交和缺失状态留下证据。

把结论写有限

同时交付对照、风险、负结果与不足；模拟演示经过检查，也仍然需要真实数据验证。

本系列的终点是一套可复现、可答辩的基础研究流程。当前课程保持静态多因子范围，不用动态配置、机器学习或更复杂工具来掩盖基础口径问题。正式项目能否获得有价值的结果，需要由更多真实、完整且时间对齐的数据和预先规划的检验回答；一个诚实、可复核的“证据不足”，也是合格的研究结论。
