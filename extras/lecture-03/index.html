01 / From observation to measurement

因子：把“看起来像”变成“可以计算”

观察走势图时，人很容易说“这只股票最近涨得快”“那只股票波动很大”“今天成交特别活跃”。这些描述可能有价值，但不同人理解的“最近”“快”“大”并不相同。因子工程的第一步，是把这些模糊判断变成可重复执行的定义。

因子是描述证券某种特征的数值变量。它可以来自价格、成交、财务或其他信息。本期只研究三种量价因子：用过去20日的价格变化描述趋势，用过去20日收益率的标准差描述波动，用过去20日换手率均值描述交易活跃度。这里的“日”在正式研究中应由交易日历定义。

直觉观察可操作的定义仍然需要验证的问题
最近上涨较多MOM20：当前调整价 ÷ 20期前调整价 − 1。高动量是否与之后收益有关？在哪个样本和市场环境下？
价格变化比较剧烈VOL20：最近20个日收益的样本标准差。高或低波动是否具有预测价值？
交易比较活跃TURN20：最近20日换手率的算术平均。活跃度反映关注、分歧、流动性还是短期拥挤？

一个因子，不是一条买卖指令

假设模拟股票A的20日动量为10%，B为−2%。我们只能据此说，在这套价格和窗口定义下，A的过去涨幅高于B。是否买A，还需要研究假设、因子检验、风险控制、组合规则和交易执行。单独一个数值既不保证未来上涨，也不能告诉你该买多少、何时成交。

  1. 金融问题想描述趋势、风险还是活跃度？
  2. 明确公式字段、单位、窗口、时间口径
  3. 构建与整理分股计算、缺失、MAD、Z-score
  4. 交付检验可解释的因子表，交给第四讲评价

为什么只选这三个？

它们可以从行情及换手信息构建，数学门槛适合初学者，也分别对应趋势、风险和活跃度三个角度。但“名字不同”不等于“信息独立”；股价大幅变化时，波动与换手也可能同步变化。因此本讲最后会检查相关性，而不会直接假设三个因子就带来三倍信息。

研究假设与结论要分开。

本课可以提出“较高动量、较低波动或较低换手可能有研究价值”的教学假设，但在完成检验前，不把任何方向写成普遍有效的投资规律。

02 / Feature, label, hypothesis

当前能知道的特征，和事后才能知道的答案

我们给股票编号 i，给研究日期编号 t。Xi,t 表示股票i在t时点的特征，例如收盘后算出的20日动量；Yi,t 表示为了事后评价而记录的未来结果，例如从t到t+20的调整价收益。符号本身并不防止泄漏，关键是每一列当时是否已经可得。

Xi,t = MOMi,t(20) = Pi,t / Pi,t−20 − 1
Yi,t(20) = Pi,t+20 / Pi,t − 1上式Y是用于评价的收盘到收盘价格收益标签，不含费用；不是收盘后才发出信号时已经实现的可交易收益。

在t日收盘后，Pi,t和此前历史可以进入特征；Pi,t+20必须等未来走完才知道。把未来标签放入当期排序，等于在答题时偷看答案。即使代码只写了一行 shift(-20)，也改变不了它包含未来信息的事实。

把研究假设写成可被否定的句子

“动量很有用”太宽泛。更清楚的写法是：“在预先确定的A股历史股票池、调整价格、20日窗口和样本划分下，t日可用的动量排名与之后20个交易日的收益排名存在稳定的统计关系。”这句话说明对象、定义和评价方向，也允许数据否定它。第四讲再用Rank IC和分组检验寻找证据。

字段t日收盘后可知？允许的用途
当前收盘价、过去20日收益与换手在最终行情确已发布的前提下，可以。构建当前特征，进一步考虑下一可执行时点。
未来20日收益不可以。事后标签、研究评价，不能进入当前输入。
未来是否退市、最终测试期表现不可以。不能据此倒推当时股票池或调方向。

一张表里同时有X和Y时怎么办？

存储时可以用明确的命名和分区保存，但形成当期得分时应使用特征白名单，而不是“把所有数值列都算进去”。本讲完整实验只构建当时可用的因子，不生成预测模型，也不利用未来收益选择方向。它为第四讲提供输入，而不会提前给出因子有效的结论。

03 / Two axes of a panel

先沿时间计算，再在同一天比较股票

股票数据有两条重要的轴。沿着一只股票从过去到现在移动，是时间序列；固定同一天，横向比较不同股票，是横截面。三个原始因子沿时间计算，MAD和Z-score则在每个研究日期的股票横截面上处理。

真实存储常用长表，一行是“symbol × trade_date”，包含价格和多个因子列。长表便于分组、关联与写入数据库；上表的宽矩阵更适合解释两条轴。两种展示方式描述的是同一组数据，不应因为换了形状就丢失主键或打乱顺序。

import pandas as pd

panel = pd.DataFrame({
    "symbol": ["SIM001", "SIM001", "SIM002", "SIM002"],
    "trade_date": pd.to_datetime(["2024-01-02", "2024-01-03"] * 2),
    "adj_close": [10.0, 10.5, 20.0, 19.8],
})
panel = panel.sort_values(["symbol", "trade_date"]).reset_index(drop=True)
panel["ret_1d"] = panel.groupby("symbol")["adj_close"].pct_change(fill_method=None)
wide = panel.pivot(index="trade_date", columns="symbol", values="adj_close")
print(panel)
print(wide)
  1. 前两步建立一个只有两天、两只股票的模拟长表，日期显式解析成日期类型。
  2. sort_values 保证每股记录按时间排列；行索引只是pandas位置标签，业务键仍是代码和日期。
  3. groupby("symbol") 沿时间轴独立算每股收益；SIM002第一条不应接上SIM001的最后价格。
  4. pivot 把代码变成列、日期变成行，方便观察结构。若同股同日重复，pivot会报错，这也是一个质量提示。

两类分组不要混淆

groupby("symbol") 负责过去窗口；groupby("trade_date") 负责同日股票比较。如果把所有年份放在一起标准化，历史早期的均值就会受后来股票和行情影响，还可能引入未来分布信息。如果按股票自身全历史标准化，得到的又是“这只股票相对自己的历史位置”，不是本项目要比较的同日横截面得分。

本讲的一句操作顺序

按代码和日期排序 → 在每股的完整日期网格上计算原始因子 → 每个日期筛选当时共同有效样本 → 在该横截面去极值、标准化与方向处理。

04 / Momentum

20日动量：过去这段时间，价格改变了多少？

动量把“最近涨得较快”变成一个相对价格变化率。本课定义的是20个交易间隔的简单价格收益，不是20个价格的平均涨幅，也不是把20个日收益直接相加。真实项目中的P应来自一致、已确认的调整价格口径。

MOMi,t(20) = Pi,t / Pi,t−20 − 1i是股票，t是研究日，20是过去的交易间隔数。需要从t−20到t共21个价格，而不是20个。

模拟例子：20个间隔前为10元，当前11元，动量就是11÷10−1=0.10，即10%。若当前9元，动量为−10%。数学公式只使用两端价格；本实验额外要求21个价格完整，是保守的质量政策，并非公式需要中间每个价格才能相除。它只描述起终点的变化；两条路径可以有相同动量，却经历完全不同的波动与回撤。

金融直觉可以解释方向，但不能替代检验

一种研究思路是：信息被逐步理解、投资者反应存在延迟，趋势可能在部分时期延续；另一面是短期过热、交易拥挤或反转。仅凭这些故事，无法决定本课20日动量在A股一定为正向。经典动量研究的市场、窗口与样本也不等于本项目的设置，必须重新检验。

Python：端点公式加上窗口完整性检查

g = panel.groupby("symbol", sort=False)
panel["mom20"] = g["adj_close"].transform(
    lambda s: (s / s.shift(20) - 1).where(
        s.rolling(21, min_periods=1).count().eq(21)))

shift(20) 拿到同股20行之前的价格；在完整交易日期网格上，这才对应20个交易间隔。rolling(21).count() 检查当前及前20行共有21个有效价格，where 只保留完整窗口。单看端点不够：中间若有漏采，端点公式仍可能算出数，但本课选择先保留缺失、等待核对，而不假装窗口完整。

常见错误：把20个价格误当成20日收益。

从第1个价格到第20个价格只有19个间隔。与此类似，20个日收益需要21个连续有效价格。不要为了让第一条指标更早出现，把窗口悄悄缩成19期。

它与日收益累乘是什么关系？

1 + MOM20,t = ∏k=0…19(1+rt−k)在连续且口径一致的价格序列上成立。逐日简单收益应累乘，不是直接相加；分红与调整口径仍须一致。

这个等式也是验算办法：同一完整窗口内，用端点价格比与日收益累乘计算，应在浮点容差内一致。本讲不通过调整窗口去追求漂亮的预测结果，20期定义在检验前固定。

05 / Volatility

20日波动率：衡量收益变化的离散程度

波动率不是价格涨幅。两只股票都可能从10元涨到11元，其中一只每天变化很小，另一只中途大涨大跌。动量对这两只股票给出相同的起终点收益；波动率则试图描述日收益围绕其均值变化的幅度。

我们先用调整价格计算简单日收益 ret_1d，再求最近20个日收益的滚动样本标准差。本项目使用 ddof=1，不在这一因子中做年化，也不把原始价格的标准差当成收益波动率。

ri,t = Pi,t / Pi,t−1 − 1
VOLi,t(20) = √[ Σk=0…19(ri,t−k − r̄i,t)² / (20−1) ]r̄为窗口内20个日收益的算术平均；分母19来自样本标准差ddof=1。日收益用小数，波动率也用同样的小数单位。

先用4个收益做一次手算

取模拟收益1%、−1%、2%、−2%。均值为0；平方偏差之和为0.001（使用小数0.01等计算）。样本方差为0.001÷3，标准差约0.018257，即1.8257%。如果用总体口径除以4，会得到约1.5811%，两种数值不能混用。

import pandas as pd

r = pd.Series([0.01, -0.01, 0.02, -0.02])
print(f"样本标准差：{r.std(ddof=1):.6%}")
print(f"总体标准差：{r.std(ddof=0):.6%}")

四个小数分别代表四期收益。std(ddof=1) 的分母是n−1，ddof=0 的分母是n；格式 :.6% 只改变显示，不改变数据本身。这个4期小表用于理解公式，正式因子仍要求20个完整日收益。

Python：为什么第一条有效值仍需要21个价格？

panel["ret_1d"] = panel.groupby("symbol")["adj_close"].pct_change(fill_method=None)
panel["vol20"] = panel.groupby("symbol")["ret_1d"].transform(
    lambda s: s.rolling(20, min_periods=20).std(ddof=1))

第一行明确不填补价格缺失；每只股票首个价格没有前值，所以首个日收益为空。第二行的20个完整日收益，实际依赖21个连续价格。min_periods=20 防止只有几条历史时也生成看似可比较的波动率。缺一个价格通常会影响它所在日及后一日的收益，随后通过滚动窗口继续影响VOL20。

低波动是否更好？先留作问题

低波动可能与风险约束、投资者偏好等研究问题有关，但“波动低”与“未来收益高”不是同一个陈述。高波动也不等于必然亏损。这里计算的是历史总体变化幅度，包含上涨与下跌波动，并不是只关注亏损的下行风险度量。

口径固定再比较

本讲VOL20不乘√252。后续报告若展示年化波动率，应另设明确字段，并说明使用日频收益、年度交易日近似与样本标准差口径。不能把日波动与年波动混在同一截面或表格里。

06 / Trading activity

20日平均换手率：交易活跃，究竟意味着什么？

成交量说的是交易了多少股，换手率尝试把交易规模放到可流通股本的背景中。相同的100万股成交，对流通股本1000万股的股票和10亿股的股票含义不同。换手率提供了相对尺度，但分母定义必须向数据源确认。

Turnoveri,t = 当日成交股数 / 对应口径的流通股数
TURNi,t(20) = (1/20) Σk=0…19 Turnoveri,t−k本讲内部统一用小数：0.025表示2.5%。不是25%、也不是0.025%。分子分母都以股计量，且分母大于0。

模拟例子：成交100万股，流通股本5000万股，则换手率为0.02，即2%。它不是“有2%的股东都换了人”：它统计的是成交股数相对股本规模的比例，并不是唯一持有人变更的比例，不能据此推断有2%的股东更换。

来源或写法输入值进入本讲计算前
接口以百分数返回2.5表示2.5%除以100，存为0.025。
内部小数口径0.025保持不变，显示时可格式化为2.5%。
成交量以“手”返回本讲A股采集示例1手=100股先转成股，再除以对应的流通股数。
分母未知或口径不可验证无法确定保留缺失，不能凭股票价格或当前股本补历史。

Python：不把百分数再乘100

import pandas as pd

turn = pd.Series([0.01] * 10 + [0.03] * 10)
turn20 = turn.rolling(20, min_periods=20).mean()

高换手率可以有不止一种解释

它可能伴随信息发布、市场关注、分歧、交易流动性改善，也可能与短期拥挤和投机有关。仅观察一个活跃日，不能判断之后收益方向。本项目研究的是20日平均活跃度，不是成交量越大越应该买，也不是用高换手直接判定风险。

换手率拿不到时，替代指标必须换名字

如果数据源换手率不可用，可以在正式研究开始前另定义相对成交量，例如“当日成交量 ÷ 过去20日平均成交量”。但它衡量的是相对自身历史的量，而不是相对流通股本的换手；不能把它仍命名为TURN20或悄悄塞进相同实验。本讲默认保留缺失，不自动切换替代因子。

真实股本存在时间维度。

送转、增发、限售解禁或口径调整都可能改变分母。用今天的流通股本除过去多年的成交量，会改变历史特征。本讲模拟分母是已明确设定的，不等于已经解决真实股本的时点可得性。

07 / Information boundary

窗口向后看，评价向前看，交易再单独对齐

“只使用过去20日”不只是一个口号，需要落实为具体日期和可用时间。若t日最终收盘价、全天成交与换手率在收盘后才确定，那么包含这些字段的因子也只能在之后确认。它不能倒过来指导当天已经发生的买入。

20行什么时候才等于20个交易日？

pandas的整数窗口按行计数。若在清洗时删掉一个交易日，再直接 shift(20)，它就会回到20条观测之前，覆盖的日历长度可能更长。第二讲已经强调了“上一条观测”与“上一交易日”不同；第三讲要把这个边界进一步落实到20期因子定义。

因此本讲完整实验先建立每只股票的统一模拟交易日期网格，再对齐价格与换手率。缺失的交易记录保留为空，而不是删除后把两侧接起来。正式研究应替换为权威交易日历和当时证券状态，不能把示例的周一至周五序列直接称作A股日历。

# 已确认calendar是本次样本应覆盖的交易日期；示例不能用自然日代替
symbols = panel["symbol"].drop_duplicates().sort_values()
grid = pd.MultiIndex.from_product([symbols, calendar], names=["symbol", "trade_date"])
panel = panel.set_index(["symbol", "trade_date"]).reindex(grid).reset_index()
panel = panel.sort_values(["symbol", "trade_date"]).reset_index(drop=True)

第一行取得本次股票范围；from_product 创建代码与日期的完整组合；reindex 对缺少的组合插入空值。它补的是记录位置，不是伪造价格或成交。真实项目还要处理上市前、退市后与历史股票池，不应默认所有股票在全区间都可交易。

三种很隐蔽的未来信息

  • rolling(..., center=True) 把当前点放在窗口中间，可能引入后面的观测；本课使用默认右对齐窗口。
  • bfill() 用后来才知道的价格回填过去，可能让缺失日“提前知道”复牌价。
  • 看完最终测试期的收益后，再决定某因子取正还是取负，会把测试数据变成开发资料。

一个有力的工程检查是：修改样本后面几天的行情，再重新计算，早于修改日期的因子必须保持不变。本讲完整脚本会执行这类扰动检查；它检验计算依赖关系，不替代历史股票池、数据修订与公告可得时间的审查。

08 / MISSINGNESS & VALIDITY

缺失的因子值，是一条需要解释的信息

一张因子表出现空值，不一定说明代码出错。20期动量需要当前和20期前的价格，并在本讲的严格口径下检查中间21个价格是否完整；20日波动率需要20个有效日收益，最前面还需要一个用于计算首个收益的价格；20日平均换手率需要20个有效换手率。刚上市、样本刚开始或观察窗口不足时，条件没有满足，空值恰好表达了“证据不足”。将它填成0，会把不知道写成“没有动量、没有波动或没有交易”。

本讲沿用第二讲的原则：先区分原因，再决定处理。真实市场开市而个股缺少一行，可能是停牌、未上市、退市、漏采或供应商记录方式不同；不能只凭缺行就断言停牌。第三讲的完整实验先建立明确的模拟日期网格，再把行情放回网格，缺口保留为空。这样窗口20才对应这个网格中的20个时点，不会因为删掉坏行而悄悄向更早的记录延长。

现象含义与检查本讲处理
历史不足窗口尚未集齐；不是经济意义上的零。保留NaN，记录首次可计算日期。
窗口内价格缺失会影响动量连续性和相邻日收益；一个缺价可能使多日窗口失效。不插值、不前向填充；相应窗口留空。
换手率未知没有可靠流通股本，或来源字段缺失。TURN20留空；不得拿成交量直接冒充换手率。
极端但有限的因子值可能是真实市场状态，也可能是单位、复权或原始数据问题。先核查来源；确认可用后才进入预先规定的去极值流程。
无穷大、负波动率或负换手率无穷大可能来自零分母；后两者违反本讲字段定义。标记异常并排除，保留原因，回查上游。

为横截面比较定义同一份有效样本

如果动量用8只股票、波动率用6只、换手率用5只，各列标准化时面对的“平均股票”并不相同，后续比较容易混淆。本讲采用一条明确、保守的规则：在每个日期，先从预先规定的研究股票池中挑出三个原始因子都有效的股票，再让三个因子使用这份共同样本。共同有效股票少于5只时，当日标准化得分留空。这是教学协议，不是所有量化项目必须遵守的固定门槛。

import pandas as pd

sample = pd.DataFrame({
    "symbol": [f"SIM{i:03d}" for i in range(1, 7)],
    "trade_date": pd.Timestamp("2024-03-01"),
    "mom20": [0.10, 0.04, -0.02, 0.08, 0.01, float("inf")],
    "vol20": [0.02, 0.01, 0.03, 0.025, 0.018, 0.02],
    "turn20": [0.03, 0.02, 0.01, 0.04, 0.025, 0.03],
})                                                     # 1. 六只虚构股票
cols = ["mom20", "vol20", "turn20"]
sample[cols] = sample[cols].replace(
    [float("inf"), float("-inf")], float("nan"))          # 2. 非有限值转为不可用
sample["common_valid"] = sample[cols].notna().all(axis=1)
sample["common_valid"] &= (sample["vol20"] >= 0) & (sample["turn20"] >= 0)
sample["n_common"] = sample.groupby("trade_date")[
    "common_valid"].transform("sum")                    # 3. 同日共同有效股票数
print(sample[["symbol", "common_valid", "n_common"]])

第1步构造明确标为模拟的小表，换手率使用小数。第2步同时处理正负无穷大，否则仅用notna()会把无穷大当作已知数值。all(axis=1)要求一行的三列同时有效；随后再检查波动率与换手率不能为负。第3步先按日期分组，再把有效行数写回每一行。本例有5只共同有效股票，SIM006仍留在表中作为无效记录；完整实验还输出原因，不能只让它从结果中消失。

共同样本规则也有代价。

要求所有因子同时有效，会缩小样本，并可能偏向历史更长、数据更全的证券。报告中应展示各因子的可用率、共同样本数量和排除原因。不能为了让图更好看，事后只保留未来表现较好的股票。

09 / ROBUST CLIPPING

MAD去极值：限制极端点的影响，保留原始证据

设某天五只股票的因子值为1、2、2、3、100，单位为便于手算的模拟因子点。100会把均值向上拉，也可能让标准差变得很大，使其他股票挤在很窄的标准化区间里。去极值的目的，是按照预先规定的方法限制单个极端值对横截面尺度的影响。它不是发现因子有效的证据，也不是判断100一定错误。

为什么用中位数？把数值从小到大排列，中间位置的数是中位数；偶数个样本取中间两个数的平均。中位数主要由位置决定，不容易被一个特别大的数拖走。MAD再衡量每个数偏离中位数的绝对距离，并对这些距离取中位数，因此比基于均值的尺度更耐受少量极端点。

mt = mediani(Xi,t)
MADt = mediani(|Xi,t − mt|)
Lt = mt − 3MADt，Ut = mt + 3MADt
X̃i,t = min(max(Xi,t, Lt), Ut)本讲采用原始MAD与3倍边界，不乘1.4826；i是同日共同有效样本中的股票，t是当前日期。

在手算例子里，中位数是2；绝对偏差为1、0、0、1、98；排序后偏差为0、0、1、1、98，所以MAD为1。下界为−1，上界为5。裁剪后得到1、2、2、3、5。只有100被压到5，其他数保留。这种操作也常称为缩尾或裁剪；与直接删掉极端股票不同，它保留该股票的一行，但改变了用于后续标准化的数值。

import pandas as pd

x = pd.Series([1.0, 2.0, 2.0, 3.0, 100.0])  # 1. 模拟因子点，不是实证收益
median = x.median()                        # 2. 中位数为2
mad = (x - median).abs().median()           # 3. 绝对偏差的中位数为1
if mad == 0:
    clipped = x.copy()                     # 4. 零MAD：保留并另记标志
else:
    clipped = x.clip(median - 3 * mad,
                     median + 3 * mad)     # 5. 低于下界/高于上界的值压到边界
print(median, mad, clipped.tolist())        # 预期：2.0 1.0 [1, 2, 2, 3, 5]

第1行只演示一个日期的一列因子。第2–3步对应公式，abs()表示绝对值，避免正负偏差互相抵消。第4步处理MAD恰为零的边界；第5步的clip返回裁剪后的新序列，原始x仍然保留。正式实验逐日期、逐因子做同样的事，并同时保存原值、边界、裁剪后值和状态，不能覆盖原始因子列。

动手观察：极端点怎样改变截面？

五个模拟因子点

原始值1、2、2、3、100
裁剪后1、2、2、3、5

横轴虚构股票A–E，纵轴模拟因子点。切换时纵轴会重算，请对照数值标签比较；median=2、raw MAD=1、边界[−1,5]在本滑动范围内不变。完整实验的分布图使用同一分箱与坐标。

MAD等于零，不能靠加一个很小的数掩盖

例如1、1、1、1、10的中位数为1，绝对偏差为0、0、0、0、9，MAD为0。如果仍按零宽边界裁剪，所有值都会变成1；这可能把唯一存在的差异直接抹掉。本讲预先约定：MAD为0时保留原值，并标记mad_zero=True，随后由Z-score检查是否仍有有效离散程度。不要临时加1e-8，因为这个数没有解决“尺度估计失效”的研究问题。

另一种常见约定把MAD乘以约1.4826，得到正态分布下与标准差尺度对应的估计。这个系数不是必须步骤，乘与不乘会改变裁剪强度。本讲为便于手算统一采用raw MAD、倍数3、无缩放系数；比较实验时应固定并记录约定，不能一张图用一种口径，另一张图换一种。

先核查，再裁剪。

若极端因子来自把“2.5%”误读成2.5，或复权口径混用，正确动作是修复上游字段。MAD只能限制数值影响，不能把错误数据变成可靠数据。原始图与处理后图都要保留，便于说明究竟改变了什么。

10 / CROSS-SECTIONAL SCALE

Z-score：把不同因子放到可比较的尺度上

动量是价格变化比例，波动率是收益的离散程度，换手率是交易活跃度；即使都以小数表示，它们的典型数值范围仍然可能不同。把三列原始值直接相加，会让数值尺度更大的列拥有更大影响力。这个隐含权重来自计量方式，未必来自你的研究判断。标准化先把各列放到同一日期内的相对位置尺度，再讨论方向与组合。

本讲在MAD裁剪后，使用当前日期共同有效股票的横截面均值和总体标准差。这里的“总体”是指当日研究样本本身，代码采用ddof=0；它不是说已经包含市场上所有股票。前面的VOL20衡量时间序列收益波动，采用样本标准差ddof=1。这两处统计量的用途不同，参数必须各自写清楚。

μt = (1/nt) Σi X̃i,t
σt = √[(1/nt) Σi(X̃i,t − μt)²]
Zi,t = (X̃i,t − μt) / σt均值与标准差只使用同日共同有效样本；n≥5且σ>0时才输出该因子的得分。

用三个数先建立直觉

仅为手算理解，取1、2、3。均值为2，总体方差为(1+0+1)/3=2/3，总体标准差约0.816497。三个Z-score约为−1.224745、0、1.224745。正值表示高于当日样本均值，负值表示低于均值；绝对值表示相差多少个当日标准差。这个三股票例子不满足正式实验的min_n=5，只帮助理解公式，不会进入正式得分表。

import pandas as pd

def cross_section_z(x, min_n=5):
    x = x.replace([float("inf"), float("-inf")], float("nan"))
    valid = x.dropna()                              # 1. 有效值样本
    if len(valid) < min_n:
        return pd.Series(float("nan"), index=x.index)
    sd = valid.std(ddof=0)                          # 2. 当日总体标准差
    if valid.nunique() <= 1 or sd == 0:
        return pd.Series(float("nan"), index=x.index)
    return (x - valid.mean()) / sd                  # 3. 保留原索引与原有缺失

clipped = pd.Series([1.0, 2.0, 2.0, 3.0, 5.0])      # 4. 上一节模拟裁剪结果
z = cross_section_z(clipped)
print(z.round(6).tolist())
print(round(z.mean(), 10), round(z.std(ddof=0), 10)) # 预期：0.0、1.0

第1步先确定有效样本数；这里单独演示一列，正式流程传入的是已经筛好的三因子共同样本。少于5只时返回同长度的空序列。第2步显式写ddof=0；所有数相同时无法除以0，所以输出空值而不是把0/0当作得分0。第3步逐股票减均值、除标准差；第4步用五个模拟点核对。浮点数存在舍入误差，均值通常接近0、标准差接近1，不要求每个字符恰好等于十进制的0或1。

标准化的边界：它不创造预测信息

同一截面内，正标准差的线性标准化不会改变这一列的大小顺序；MAD裁剪可能让多个极端值相同，从而出现并列。Z-score也不意味着因子服从正态分布，不能因为得分为2就直接套用正态分布概率，更不能把高分称为“上涨概率更高”。得分只描述相对位置，预测能力留到第四讲检验。

不要把全部年份、全部股票混在一起求一个均值和标准差，再回填到历史日期。未来年份的数据会进入过去的尺度，违背历史时点可用性；不同日期的市场环境也可能被混为一谈。横截面标准化使用当天已经可见的股票池与因子；它和机器学习中按开发样本拟合的变换器不是同一种任务，本课程此处不引入后者。

标准差为零，不等于研究上“没有风险”。

它只表示当前这份横截面样本的该因子完全相同，无法给股票区分位置。某只股票的VOL20很低，与当日所有股票的VOL20恰好相同，是两个不同层次的问题。

11 / PREDECLARED DIRECTION

统一方向：先说清楚“高分”代表哪种研究假设

Z-score为正，只意味着原始因子相对较高，并不自动意味着更值得买入。例如在一种动量延续假设下，较高MOM20可能被赋予较高研究得分；在一种低波动假设下，较低VOL20反而得到较高分。方向统一就是显式写出这个映射，让后续的“高分”具有一致的假设含义。

Fi,t(j) = dj · Zi,t(j)，dj ∈ {+1, −1}d是预先确定的方向；它不会改变原始因子的金融定义，也不会把假设变成结论。
因子本讲演示方向“高得分”的含义必须保留的边界
MOM20+1相对较高的过去20期动量不保证趋势延续，短期也可能反转。
VOL20−1相对较低的历史日收益波动低波动不等于高未来收益或没有亏损。
TURN20−1相对较低的历史平均换手率只是固定教学假设；高换手也可能对应信息交易或流动性优势。

换手率尤其需要避免一句话解释。高换手可能伴随交易拥挤、分歧、关注度上升，也可能反映信息进入价格或较好的可交易性。把它设为负向，并不是宣布“低换手股票一定更好”。本讲的三项方向在生成模拟数据与分析结果前固定下来，仅用于练习工程流程；未来是否保留，要依赖开发阶段的金融逻辑和统计证据。

import pandas as pd

z = pd.DataFrame({"mom20": [1.0, -1.0],
                  "vol20": [-1.0, 1.0],
                  "turn20": [0.5, -0.5]},
                 index=["SIM001", "SIM002"])        # 1. 模拟标准化结果
directions = pd.Series({"mom20": 1, "vol20": -1,
                        "turn20": -1})             # 2. 预先声明，不从未来挑选
oriented = z.mul(directions, axis="columns")         # 3. 按列名对齐方向
print(oriented)

第1步只是两只股票的方向代数演示，数值不是本实验完整截面的真实输出，也不是在绕过min_n规则计算Z-score。第2步把方向写成可审计的参数。第3步按列名相乘，避免把一个方向误用到另一列；SIM001较低的波动率Z值−1乘以−1后得到正的方向得分1。此处没有相加、选股或生成买卖指令，多因子合成与回测留到第五讲。

用最终测试集调方向，会把答案带回题目

一个常见错误是先看完整历史收益，发现动量表现不好就改成反转，发现高换手不赚钱就换成低换手，再把同一段历史称为“样本外成功”。这相当于用考卷答案修改规则。合理流程应按时间划分开发、验证、最终测试：开发阶段提出并比较有限的假设，验证阶段帮助确定方案，最终测试前冻结方向和其他关键设置。

如果最终测试显示方向不稳定，应记录这一结果，而不是偷偷翻转符号后再汇报。后续可以提出新假设，并寻找新的未使用样本，但旧测试集已经不再提供未使用样本的独立证据。第四讲会讨论有效性与不确定性；第三讲先把方向参数、设定理由和冻结时间写进因子定义表。

12 / REDUNDANCY & CORRELATION

三个因子，不一定带来三份独立信息

一只股票近期剧烈上涨时，动量可能较高，日收益波动可能增加，成交活跃度也可能上升。三个公式使用不同名字，不代表它们刻画了完全不同的股票特征。如果两列高度相似，后续等权合成可能在不知不觉中反复强调同一种暴露。相关性分析帮助我们识别重叠，而不是直接决定删除哪一个因子。

本讲先问一个范围明确的问题：在同一个日期、同一份共同有效股票样本里，两列因子如何一起变化？使用横截面Pearson相关系数，观察两列数值的线性共同变化。相关系数接近+1表示同向线性关系较强，接近−1表示反向线性关系较强，接近0只表示线性关系弱，不排除非线性关系，也不代表两者独立。

ρXY,t = Σi(Xi,t−X̄t)(Yi,t−Ȳt)
÷ √[Σi(Xi,t−X̄t)² · Σi(Yi,t−Ȳt)²]只使用相同日期、相同股票；若任一列没有离散程度，相关系数不可定义，应保留缺失。

先写清样本，再画热力图

import pandas as pd

cross = pd.DataFrame({
    "mom20": [0.10, 0.04, -0.02, 0.08, 0.01, 0.06],
    "vol20": [0.020, 0.010, 0.030, 0.025, 0.018, 0.022],
    "turn20": [0.030, 0.020, 0.010, 0.040, 0.025, 0.028],
}, index=[f"SIM{i:03d}" for i in range(1, 7)])       # 1. 同日六只虚构股票
common = cross.dropna(how="any")                    # 2. 同一共同样本
matrix = common.corr(method="pearson", min_periods=5)
print("n_common =", len(common))                    # 3. 报告实际股票数
print(matrix.round(4))

第1步构造同一日期的小截面，动量、波动率与换手率均用小数表示。第2步先统一完整样本，避免每个相关系数使用不同股票。corr计算两两Pearson系数，min_periods=5要求至少5个配对观测。第3步报告数量；完整报告还应标注日期、原始还是处理后因子、价格与换手口径。真实实验中还要先限制预先定义的股票池，不能用未来入选名单回看过去。

原始因子、MAD裁剪后因子、标准化后因子和方向得分，回答的是不同阶段的问题。在同一完整样本且标准差为正时，正尺度Z-score不会改变Pearson相关；MAD裁剪可能改变它，方向乘以−1会翻转相关符号。因此一张标成“因子相关性”的图若没有说明处理阶段，读者就不知道应如何解释正负号。

相关性不是因子有效性检验

两列因子互不相关，不意味着它们都能预测收益；两列高度相关，也不意味着其中一列永远没有额外价值。这里矩阵的两边都是当期因子，没有使用未来收益。第四讲的Rank IC则比较当期因子与未来收益排名，两者的研究问题不同。不要看到这个热力图的数字很大，就把它写成预测能力强。

一个日期只有几只股票时，相关系数很容易受某个样本支配。完整研究应按多个预先规定的日期分别计算，再观察关系是否稳定，并同时报告样本量；把全部年份和股票简单堆成一个相关系数，可能混合日期间市场状态与日期内股票差异。本讲只给出一个可解释的单日截面，避免用大表的行数制造虚假的确定感。

练习1：20期动量究竟需要几个价格？

某只虚构股票20个模拟交易时点前价格为10元，现在为11元。计算MOM20。若中间第8个时点价格缺失，但两个端点都存在，本讲严格完整窗口规则应输出什么？请同时说明，改用“上一20条可用记录”的结果为什么不能直接叫作同一口径的20日动量。

展开答案、独立代码与评分标准 
import pandas as pd

p = pd.Series([10.0 + i * 0.05 for i in range(21)]) # 1. 21个连续模拟价格
mom = p / p.shift(20) - 1                          # 2. 当前与20期前比较
valid = p.rolling(21, min_periods=21).count().eq(21)
mom = mom.where(valid)                            # 3. 完整性作为单独条件
print(round(mom.iloc[-1], 6))                      # 0.1，即10%
p.iloc[8] = float("nan")
print(p.rolling(21, min_periods=21).count().iloc[-1] == 21) # False

第1步准备21个价格才能包含20段变化；第2步得到0.1，不是10这个小数；第3步要求窗口内所有价格都存在。因此缺失发生后，严格MOM20留空，即使端点公式仍能计算。按可用行跳过缺口会扩大实际时间跨度。评分10分：公式与10%结果3分、21价格边界3分、缺口与观测口径解释4分。

练习3：从MAD裁剪走到标准化

用1、2、2、3、100计算中位数、原始MAD、3倍边界与裁剪结果，再计算裁剪后Z-score。说明为什么必须保存原始值。若换成1、1、1、1、1，Z-score应怎样输出？

展开可运行答案与边界解释 
import pandas as pd

x = pd.Series([1.0, 2.0, 2.0, 3.0, 100.0])
m = x.median()
mad = (x - m).abs().median()
c = x.copy() if mad == 0 else x.clip(m - 3 * mad, m + 3 * mad)
sd = c.std(ddof=0)
z = (c - c.mean()) / sd if sd > 0 else c * float("nan")
print("median, MAD:", m, mad)       # 2与1
print("clipped:", c.tolist())      # [1, 2, 2, 3, 5]
print("mean, sd:", z.mean(), z.std(ddof=0)) # 浮点容差内为0与1

原始值保留后，才能区分“供应商本来是100”与“研究变换把它改成5”，并比较处理强度。全为1时MAD为0，按本讲规则保留；随后总体标准差也为0，得分全部为空。不能用一个很小的分母编造巨大得分，也不能声称这些股票没有未来风险。评分10分：MAD与边界4分、Z-score口径3分、零尺度与追溯3分。
