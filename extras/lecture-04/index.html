01 / From a story to evidence

金融逻辑，为什么还需要接受数据检验？

“近期涨得多可能继续涨”“低波动也许有优势”“换手率反映市场关注”都是可以提出的研究思路。一个故事听起来合理，并不自动说明它在某个市场、窗口、样本和交易成本下具有可用价值。因子检验把故事转成清楚的问题，并允许数据给出不支持的答案。

例如研究20日动量，我们需要说清楚：使用哪一套价格、哪个历史股票池、t日何时形成因子、之后哪20个交易间隔作为评价、哪些日期参与检验、哪些样本被排除。若定义不断随结果改变，就很难判断观察到的是稳定关系，还是反复尝试后留下的偶然成功。

  1. 冻结定义价格、窗口、股票池与方向
  2. 对齐X与Y当期因子与事后未来标签
  3. 多角度评价IC、时间稳定性、分组与冗余
  4. 限定结论样本外、不确定性与后续交易验证

三种判断，需要不同证据

判断需要看什么不能直接推出什么
计算符合定义手算、数据质量、代码与时点检查。不能仅凭程序正确就宣布因子有效。
存在统计上的预测关系IC、分组、稳定性、样本量与独立检验。不能保证每只高分股票都上涨，也不能据此证明因果。
可以转成策略收益实际执行时点、组合权重、成本、限制与风险。本讲的相关系数和未来收益均值不是策略净值。

先练习报告完整结果

如果预先固定的方向得到负IC，应保留该结果，解释它在当前样本中的含义。若分组不单调或样本太少，也应报告。研究的目标是判断假设得到怎样的支持，而不是确保每次实验都“成功”。下一讲再讨论如何把通过检验的研究方案变成可检查的策略回测。

02 / Align features and outcomes

把当期因子，和事后未来收益一一对应

对股票i和研究日t，我们记当时可用的因子得分为Fi,t，用于事后评价的未来20期收益为Yi,t。第三讲的得分只能使用t日及之前的信息；标签需要等到t+20之后才能观察。它们可以为研究存到同一张表，但职责必须分开。

Yi,t(20) = Pi,t+20 / Pi,t − 1P为一致口径的调整价格。本课Y是t日收盘到t+20日收盘的价格收益标签，不含成本，也不等于收盘后产生信号时可执行的持仓收益。

本实验先按第三讲完整流程计算因子，再单独添加标签。未来列不会参与MAD、Z-score或方向选择。标签同样使用完整日期网格，并额外要求t到t+20共21个有效价格，这是保守的质量政策；数学端点公式本身只用两端价格。

# panel已按symbol、trade_date排序，并对齐同一完整交易日期网格
g = panel.groupby("symbol", sort=False)
panel["label_end_date"] = g["trade_date"].shift(-20)  # 1. 未来标签何时成熟
panel["future_return_20"] = g["adj_close"].transform(
    lambda s: (s.shift(-20) / s - 1).where(
        s.rolling(21, min_periods=1).count().shift(-20).eq(21)))
  1. shift(-20) 将同股20行之后的记录对齐到今天，因此这段代码明确包含未来信息，只能生成评价标签。
  2. 未来21价格计数先在窗口终点计算，再向前对齐到起点。缺口不会被删掉后跳过，也不填成零收益。
  3. 每股最后20个日期没有完整未来，标签应为空。不能因为它们没有标签，就把这些股票从历史时点的可选股票池中抹掉。

事后配对样本，不是当时的选股池

计算某日相关性时，必须拿到那一批股票的F和Y。本课比较三因子，先使用“同日三个得分与标签都有限”的共同配对样本，保证比较对象一致。这是评价时的可用样本，不能反过来决定当时允许买哪些股票。若未来收益缺失与退市、长期停牌或漏采有关，删掉这些记录可能造成选择偏差，真实研究应调查原因、报告覆盖并设计合理处理。

03 / Rank information coefficient

Rank IC：因子排名，与未来收益排名有多一致？

固定一个日期，把许多股票放在一起看。如果高因子得分的股票，事后未来收益也倾向于排得更高，那么两组排名会比较一致；如果高得分对应较低未来收益，则方向相反。Rank IC用一个相关系数描述这种横截面的单调对应关系。

ICt = Spearmani(Fi,t, Yi,t)
= Corri(rank(Fi,t), rank(Yi,t))每个t只比较同一天的股票。Spearman可理解为两组平均秩的Pearson相关；有并列时必须采用一致的平均秩处理。

Rank IC的范围为−1到1。+1表示两组排名完全同向，−1表示完全反向，接近0表示这里的单调排名关系弱。它不表示“预测正确的股票比例”；IC=0.8不等于80%的股票上涨，也不等于有80%概率赚钱。

为什么使用排名？

排名关注相对顺序，而不是要求原始因子和收益之间满足线性比例。一种保持顺序的严格递增变换不会改变排名。它适合问“高分股票是否倾向于有更高未来收益”。不过，它仍会受样本、并列、噪声与共同市场结构影响，也不能捕捉所有非线性关系。

Pearson相关关注线性共同变化，也对正尺度的单位变换不敏感；不能把Spearman的用途解释成“只有它才可以比较不同单位”。本讲选择Rank IC，是为了对齐股票排序问题。零相关不代表独立，相关也不能单独建立因果关系。

并列、常量与不足样本

如果两只股票因子值相同，应给它们平均秩，例如占据第1和第2名时都取1.5；不能按代码顺序随意造出高低。若某列全部相同，排名没有离散程度，相关系数不可定义，应保留缺失。若有效股票太少，也先返回状态。本课min_n=5是教学协议，不是“5只股票就足以可靠推断”的通用标准。

import pandas as pd
from scipy.stats import spearmanr

sample = pd.DataFrame({
    "factor": [0.12, 0.04, -0.03, 0.08, 0.01],
    "future_return": [0.05, -0.01, -0.04, 0.07, 0.02],
})
pairs = sample.replace([float("inf"), float("-inf")], float("nan")).dropna()
if len(pairs) < 5 or pairs["factor"].nunique() < 2 or pairs["future_return"].nunique() < 2:
    ic = float("nan")
else:
    result = spearmanr(pairs["factor"], pairs["future_return"])
    ic = float(result.statistic)
print(round(ic, 6))  # 模拟案例约0.8；不是显著性或投资结论

先移除非有限值，再按同一行保留完整配对。两列必须来自同一代码和日期，不能分别排序后失去对应关系。样本或离散程度不足时返回缺失；否则交给 spearmanr 处理平均秩并计算统计量。函数还返回p值，但小样本的默认p值是近似，不能未经说明直接当成精确证据，后文会单独讨论。

有并列时，公式为什么要换回定义？

MAD裁剪可能让几只股票得到相同得分。平均秩保留“它们无法区分”的事实，而无并列简式的推导条件已经不成立。完整程序会核对SciPy结果与平均秩的Pearson相关一致，并记录唯一值数量。不能为提高IC，临时给相同因子值加入微小随机数。

05 / Many cross-sections over time

一日一个IC，才看得到关系如何变化

单个日期的IC是一张截面照片。把多个预先规定的评价日逐一计算，就得到IC时间序列。本项目正式研究可按月度评价与调仓设计衔接；本课逐模拟工作日计算，是为了观察变化和窗口重叠，不代表已经构建日调仓策略。

每个日期先固定共同股票样本，再分别评价三个固定方向的得分。日期之间有效股票数可能变化，必须同时保存n、唯一值数量与状态。缺失IC保留为空，不插值、不补0，也不把它计入正负比例的分母。

为什么前后会有空白？

第一段需要20期历史因子预热，末尾20个日期还没有足够未来；中间的价格缺口也会影响有效配对。完整模拟网格共640行，标签有427个非空值；三个得分和标签共同可用的配对共223行，形成40个有效评价日。每个日期有三个IC，因此有效IC表有120行，但这不表示拥有120个相互独立的观察。

把循环写成研究流程

# panel是完整实操返回的标签表；所有因子共享同日配对样本
from scipy.stats import spearmanr
import pandas as pd

score_cols = ["mom20_score", "vol20_score", "turn20_score"]
rows = []
for date, group in panel.groupby("trade_date", sort=True):
    common = group[score_cols + ["future_return_20"]].replace(
        [float("inf"), float("-inf")], float("nan")).dropna()
    for score in score_cols:
        enough = len(common) >= 5
        varied = common[score].nunique() > 1 and common["future_return_20"].nunique() > 1
        ic = float(spearmanr(common[score], common["future_return_20"]).statistic) if enough and varied else float("nan")
        rows.append({"trade_date": date, "factor": score, "n": len(common), "rank_ic": ic})
ic_table = pd.DataFrame(rows)

外层循环固定日期，内层循环只换因子列。先统一配对样本，避免三个因子各自删行后比较不同股票；样本和离散程度不够则留空。rows保留日期、因子与样本数。完整脚本还保存更细的状态，后续汇总只使用有效IC。

06 / Mean and sign

IC均值与方向：先说明得分是怎样定义的

正IC表示当前得分较高的股票，事后收益排名倾向更高；负IC表示相反。解释符号之前，要先检查输入的是原始因子、Z-score，还是已经乘方向的得分。本课沿用第三讲固定设置：MOM正向、VOL负向、TURN负向，因此高VOL得分代表较低的历史波动。

将多个有效评价日的IC求均值，可以描述这段样本中关系的平均方向。均值为正，不表示每天都正；均值接近0，也可能混合了不同阶段的正负关系。均值不能替代时间序列、样本量与不确定性分析，更没有一个适用于所有市场、窗口和频率的固定“有效IC门槛”。

可以把负方向翻过来吗？

在开发阶段，可以根据金融假设与受控实验提出相反方向，再用未使用样本评价。但看完最终测试结果后翻转符号，再把同一测试称为成功，会让测试变成开发资料。本讲仅计算第三讲预先固定方向的结果，不按模拟表现重新优化。

高绝对值和可交易价值，是不同问题。

关系强弱、稳定性、样本不确定性和交易成本需要分别检验。IC也不是因果证明；可能存在共同市场暴露、行业差异或数据选择的影响。

07 / Mean relative to dispersion

ICIR：让平均关系和时间波动一起进入视野

两个因子可能拥有相同平均IC，但一个每期变化较小，另一个经常大幅正负切换。ICIR把平均IC除以IC序列的标准差，提供一个描述“平均关系相对时间波动”的比率。本课采用有效日期IC的样本标准差，ddof=1，不年化。

ICIR = mean(ICt) / s(ICt)
s(IC) = √[Σt(ICt−IC̄)² / (T−1)]T为有效IC数量。T<2或IC标准差为0时，比率不可用，输出缺失与原因；不把除零写成无限“优秀”。

ICIR保留均值的符号。−0.4描述当前得分方向下的负平均关系，并不是“风险调整后亏损40%”。它也不同于策略收益的夏普或组合信息比率：此处输入是IC序列，不是实际持仓收益。不要把它解读成预测准确率。

import pandas as pd
import math

def per_period_icir(values):
    x = pd.Series(values, dtype="float64").replace(
        [float("inf"), float("-inf")], float("nan")).dropna()
    if len(x) < 2 or x.nunique() <= 1:
        return float("nan")
    sd = x.std(ddof=1)
    return x.mean() / sd if math.isfinite(sd) and sd > 0 else float("nan")

print(per_period_icir([-0.10, 0.02, 0.04, 0.06, 0.18]))  # 约0.4
print(per_period_icir([0.04, 0.04, 0.04]))               # 缺失：无离散程度

先清理非有限值并只数有效期；再检查至少两个值与非恒定序列，防止浮点求和误差把常量伪装成极小标准差。ddof=1与本课约定一致。最后只在分母有限且为正时相除；完整报告同时保存T、均值、标准差和状态，不只交一个比率。

这里为什么不乘√252？

评价日频率、预测期长度与序列相关性共同影响年化解释。每日20期标签存在机械重叠，不能因为每行带一个日期就直接套用独立日收益的年化缩放。本讲统一报告每期ICIR，并把“它是否稳定、是否能推广”的问题留给下面的统计与样本外章节。

08 / STABILITY THROUGH TIME

平均IC相同，研究证据也可能不同

平均IC把一串日期压成一个数字，方便概括，也容易隐藏变化。设两组模拟因子都得到平均IC 0.04：一组在不同日期大幅正负摆动，另一组多数日期围绕0.04小幅变化。它们的平均方向相同，但预测关系的稳定程度并不相同。因此，不能只截取平均值，更不能只展示最漂亮的一段历史。

ICIR把这种直觉写成一个比率：分子是各评价日期IC的算术平均，分母是这串IC的样本标准差。本讲使用ddof=1，保持每期口径，不乘任何年化系数。它描述已观察序列的平均方向与离散程度，既不是胜率，也不是策略收益，更不是“成功概率”。

ICIR = mean(ICt) / s(ICt)
s(IC) = √[Σt=1…T(ICt−IC̄)² / (T−1)]T是实际有效IC日期数，不是原始行情行数；没有有效IC的日期应保留原因，不能补0。
固定模拟序列的实际计算，不是真实A股检验
模拟序列平均ICIC样本标准差每期ICIR应怎样解释
A0.040.100.40同样平均方向下，日期间变化更大。
B0.040.041.00这五个模拟日期内围绕均值更集中。
import math
import pandas as pd

def ic_stats(values):
    s = pd.Series(values, dtype="float64").replace(
        [float("inf"), float("-inf")], float("nan")).dropna()  # 1. 有效日期
    n = len(s)
    mean = s.mean() if n else float("nan")
    sd = s.std(ddof=1) if n >= 2 else float("nan")             # 2. 样本标准差
    if n >= 2 and s.nunique() <= 1:
        sd = 0.0                                             # 3. 常量显式处理
    ratio = mean / sd if n >= 2 and math.isfinite(sd) and sd > 0 else float("nan")
    return {"n": n, "mean_ic": mean, "sample_sd": sd, "icir": ratio}

a = pd.Series([-0.10, 0.02, 0.04, 0.06, 0.18])                 # 4. 五个模拟IC
b = 0.04 + 0.4 * (a - 0.04)                                  # 5. 保留均值、缩小偏差
print(pd.DataFrame({"A": ic_stats(a), "B": ic_stats(b)}).T.round(6))
  1. 第1步去掉不能参与统计的值，同时报告有效数量。若一个日期的IC不可定义，它不是经济意义上的零。
  2. 第2步把样本标准差口径写在代码中，避免与第三讲横截面Z-score的ddof=0混用。
  3. 第3步先识别常量，避免浮点舍入把一串完全相同的IC伪装成极小的正标准差。样本不足或分母为零时，ICIR返回缺失；不把常量正IC报告成无限稳定。
  4. 第4–5步构造两组固定数组。B把A相对0.04的偏差缩小到40%，因此均值相同、标准差也相应缩小。两组都只有五个日期，不能据此推断长期表现。

均值同为0.04，序列的起伏不同

独立模拟数组 · 5期
A：样本SD 0.10B：样本SD 0.04

A=[−0.10,0.02,0.04,0.06,0.18]，B=0.04+0.4(A−0.04)。灰虚线为共同均值。这个构造说明统计量含义，不提供市场显著性证据。

稳定性还要看哪些证据？

先看时间序列图，观察正负方向是否集中于某一小段；再报告每个日期的股票数、缺失原因、IC分布以及开发期和验证期的分段结果。可以辅助看正IC日期占比，但它忽略了幅度：很多微小正值和少数很大的负值，也可能产生并不理想的均值。任何一个单独指标都不能代替完整记录。

还应检查图形变化是否同时伴随样本变化。例如某几天缺失记录增多，只剩少量股票进入共同样本，IC突然升高，可能既包含关系变化，也包含样本构成变化。应对照同一天的人数与缺失审计，而不是立即为上涨的曲线编一个市场故事。只看有效日期而不说明被排除日期，也可能让稳定性被高估。

检查方向时必须回到第三讲的预先设定。若使用的是mom20_score、vol20_score或turn20_score，解释的已经是固定方向后的得分与未来收益的关系。平均IC为负，说明这个预定方向在当前样本中的关系相反；不能看完结果后偷偷翻转符号，再把修改后的同一段历史当作独立成功证据。

每天一个IC，不等于每天一份独立证据

本课用未来20期价格收益评价每日因子。相邻两个起点的未来收益窗口共享19段日收益，股票范围、市场环境和历史因子窗口也可能持续相关。因此，40个评价日期通常不能被理解为40次互不影响的实验。数值能计算出来，与统计推断所需的独立性条件，是两件不同的事。

不要用ICIR直接制造显著性。

只有在适当的独立同分布等假设下，才可以建立ICIR与均值检验统计量的简单关系。本课的日频重叠标签明显需要额外处理，不直接报告ICIR × √T作为有效的t统计量。每20个时点取一个非重叠收益窗口，可以展示重叠问题，但剩下的观察太少，而且非重叠也不自动保证整个IC序列独立。

09 / UNCERTAINTY & EVIDENCE

相关系数很大，为什么仍然可能证据不足？

五只股票的一次Rank IC达到0.8，听起来很高，但它仍然只是一个小横截面的观察。换一个日期、换几只股票，结果可能改变。统计推断关心的正是这种不确定性：如果没有我们声称的关系，类似或更极端的观察是否仍然容易出现？样本提供的信息，是否足以区分规律与偶然？

先明确原假设。课堂相关性例子可以研究“这组因子与未来收益没有所设定的秩关联”；置换演示则进一步假定，在原假设下，五个未来收益可以在股票之间随机配对。后者包含交换性假设，不能只因为写了一个检验函数，就认为真实市场自动满足。同行业股票、共同市场冲击和样本筛选都可能影响推断。

概念准确的阅读方式常见误读
p值在指定原假设和检验模型下，出现至少同样极端统计量的概率。“原假设为真的概率”或“因子有用的概率”。
拒绝原假设数据与所设定的原假设及模型不太相容。已经证明因果关系、一定能交易获利。
未拒绝原假设当前信息不足以拒绝；可能关系弱，也可能样本太少。已经证明关系恰好为零。
显著性水平分析前约定的一类错误控制标准，须配合假设和多重尝试理解。看到结果后挑一个能让结论成立的门槛。

小样本：先看到可能出现的其他排名

对本课五股票手算例子，可以把未来收益的五个排名全部重新配对。没有并列时共有5!=120种排列。按照本课预先声明的双侧定义，统计绝对相关系数不小于观察值0.8的排列比例。这个枚举让“至少同样极端”变成可检查的计数；它不是把数据增加了120倍，真正的股票样本仍然只有五只。

from itertools import permutations
import pandas as pd

sample = pd.DataFrame({
    "symbol": list("ABCDE"),
    "factor": [0.12, 0.04, -0.03, 0.08, 0.01],
    "future_return_20": [0.05, -0.01, -0.04, 0.07, 0.02],
})                                                           # 1. 明确模拟样本
rx = sample["factor"].rank(method="average")
ry = sample["future_return_20"].rank(method="average")           # 2. 排名
observed = rx.corr(ry)                                        # 3. 观察到的秩相关
null_values = [rx.corr(pd.Series(p, index=rx.index))
               for p in permutations(ry.tolist())]           # 4. 穷举120种配对
extreme = sum(abs(value) >= abs(observed) - 1e-12
              for value in null_values)                      # 5. 数值容差只防舍入
p_exact = extreme / len(null_values)                          # 6. 双侧绝对值定义
print(round(observed, 6), extreme, len(null_values), round(p_exact, 6))
# 预期：0.8、16、120、0.133333
  1. 第1步列出固定的模拟输入，未来收益只用于事后评价。
  2. 第2–3步将两列转成平均秩，再求Pearson相关，这就是Spearman秩相关的计算思路。
  3. 第4步固定因子排名，完整列举未来排名的配对。第5步按预先声明的绝对值标准计数，容差不是为了改变统计门槛。
  4. 第6步得到16/120。因为这里完整枚举了全部排列，不使用随机抽样置换常见的“分子分母各加1”近似。双侧p值定义也需要明确，不应在看到结果后换算法。

在这个课堂交换性模型下，p约0.1333；即使观察到0.8的相关，也不能在预设5%水平下拒绝该置换原假设。这既没有证明因子无效，也没有给出其有效概率。它只是提醒我们：五个股票的漂亮排名，还不足以支撑很强的结论。

SciPy的spearmanr会同时返回相关系数和默认p值，但官方文档提醒其p值近似在小样本下不够准确，建议考虑置换方法。本课把默认近似p与完整枚举p分开记录，不把两者混称为同一项“准确显著性”。可查阅SciPy Spearman文档与置换检验文档。

置信区间：把估计的不确定范围也展示出来

在独立同分布、方差有限及合适的大样本近似等条件下，均值的标准误可用样本标准差除以样本数平方根来理解，近似95%区间可写成均值加减1.96倍标准误。这个式子用来建立“样本信息更多，估计通常更精确”的直觉，并不是本课重叠IC数据的直接报告公式。

SE(IC̄) ≈ s(IC)/√T
近似95%区间：IC̄ ± 1.96 · SE(IC̄)仅为满足独立同分布等条件时的大样本直觉；小样本和时间相关情形需要不同处理。本课不据此给40个重叠日期硬算显著性。

置信区间也不是“因子有95%概率有效”。它描述一个在模型假设成立时、重复抽样下具有相应覆盖率的区间构造方法。真实研究可能需要更长样本、非重叠持有期设计，或适合时间相关性的稳健标准误与分块方法；这些方法仍各有假设，并非加一个函数就能修复所有偏差。

统计上可区分，不等于经济上有价值

在足够大的、合适设计的样本中，很小的关系也可能具有统计显著性；但它未必足以覆盖成本、风险与执行限制。相反，小样本中的高相关可能很不稳定。研究报告应同时给出关系幅度、稳定性、样本量和不确定性，不寻找一个适用于所有市场的“平均IC有效阈值”。第四讲先判断预测关系的证据，第五讲才评估其能否转化为合理的策略表现。

样本数量有两个维度。

每个日期的股票数影响横截面关系的估计，评价日期数影响时间稳定性的判断；共同市场冲击与窗口重叠又会减少独立信息。报告“共有640行行情”，不能代替报告“每期几只股票、几期有效IC、多少期独立或相关的观察”。

10 / Sort stocks, then inspect outcomes

五分组检验：让一个相关系数展开成五组结果

Rank IC把一张截面概括成一个数。分组检验则保留更多形态：先按当期因子得分从低到高排序，再分成五组，事后观察各组未来收益。高得分组是否较好、低得分组是否较差、中间组是否有顺序，都可以从图上讨论。

本课Q1是低得分组，Q5是高得分组。得分已乘第三讲固定方向，因此VOL的高得分对应较低历史波动，而不是较高原始波动率。分组只能由当期得分决定，不能先按未来收益分成赢家和输家，再声称因子有区分能力。

R̄g,tforward20 = (1/ng,t) Σi∈G(g,t) Yi,t
组均值 = 对有效评价日的 R̄g,tforward20 再取算术平均先在每个日期、每组内按股票等权；再按日期等权。它是20期未来价格收益的评价统计，不是单日策略收益，不能直接累乘净值。

Python：先确认真正形成了五组

import pandas as pd

sample = pd.DataFrame({
    "symbol": [f"SIM{i:03d}" for i in range(1, 11)],
    "mom20_score": [-1.2, -0.9, -0.6, -0.3, -0.1, 0.1, 0.3, 0.6, 0.9, 1.2],
    "future_return_20": [-0.04, 0.01, -0.02, 0.02, 0.00, 0.03, 0.01, 0.04, 0.03, 0.05],
})                                                     # 1. 同日10只虚构股票
q = pd.qcut(sample["mom20_score"], q=5, labels=False, duplicates="drop")
if q.nunique() != 5:
    raise ValueError("实际不足五组，应记录原因而非随意拆并列")
sample["quintile"] = q + 1                             # 2. Q1低分，Q5高分
summary = sample.groupby("quintile").agg(
    mean_forward_return_20=("future_return_20", "mean"),
    n_stocks=("symbol", "count"))                       # 3. 均值同时报告人数
print(summary)

第一步是独立的10股课堂小例子，不是完整实验的8股数据。qcut按因子值的分位位置划组，duplicates="drop"允许重复边界被丢弃；因此仍要检查实际组数。第二步把组号从0–4改成易读的1–5。第三步对每组未来收益取均值并保留人数。本例每组两只，真实日期人数可能不同，不能只画收益不报告n。

并列不能靠股票代码制造差异

如果很多股票得分相同，分位边界可能重复，最后只有四组甚至更少。强行按代码打散这些股票会产生没有因子依据的区分。本实验要求至少5个不同得分、实际得到5个分组；否则记录原因，保留原母表，不把“传入q=5”当成已经完成五分组。

共同有效日期上的五组均值

模拟 / — 个共同评价日

横轴Q1低得分至Q5高得分，纵轴为平均未来20期价格收益；不同因子切换时采用相同纵轴范围。图中日期窗口重叠，不能将这些均值当作独立的月收益或据此复利。

比较因子前，先比较样本覆盖

在固定模拟数据中，MOM、VOL、TURN分别只有39、40、32个日期真正形成五组；三因子的IC仍各有40个有效日，两种检验的条件不同。主图取三者共同可成立的日期交集，便于保持比较区间一致；原始各因子可用日结果与跳过原因也单独输出。样本交集仍是一个有条件的评价范围，必须报告，不等于还原了真实市场完整股票池。

11 / Read the pattern with context

分组图怎样解释，才不把噪声读成规律？

在正向得分假设下，如果从Q1到Q5的未来收益整体提高，会与“高分倾向更好”的假设相符。但一次图形不必严格单调，严格单调也不自动代表结论可靠。观察时间跨度、组内人数、极端值与样本外表现，才能讨论证据强弱。

观察形态可以提出的问题需要继续检查
Q1到Q5大体递增是否支持当前得分方向？多少日期、是否稳定、是否仅由少数股票带动？
高低组有差，中间组混乱关系是否主要集中在极端组？人数、尾部异常、分位边界与并列处理。
呈U形或倒U形单调排名是否遗漏其他关系？需要新的预先定义假设与未使用样本，不能当场反复改规则求成功。
各组都上涨是否只是共同市场行情？它们是价格收益，不直接称作相对基准的Alpha。
各组差别很小或反向当前样本是否不支持假设？保留负结果，核查数据与功效，避免事后翻方向。

一个小样本，为什么容易被单只股票影响？

完整演示每日只有5–7只共同配对股票，五组中不少组只有一只股票。那一只股票的未来价格变化就会直接成为组均值。即便跨多个日期平均，同一股票可能多次出现，窗口也相互重叠，因此不能只数柱子的数量或总行数来判断证据充分。

完整实验保留组成员、每组人数、每日期结果、平均人数和评价期数。手工挑一个日期或删掉一只表现不佳的股票，可能明显改变图形；这种事后选择也会改变研究问题。正式项目应使用更充分的数据，检查预先规定的子区间、历史股票池与稳健性，而不是只展示最好看的一张图。

分组差异怎样连接后续研究？

Q5与Q1的均值之差可帮助描述区分度，但它仍是统计比较，尚未考虑可交易时点、做空约束、持仓路径或费用。本讲不把这个差直接称作可实现的多空策略收益。第五讲再将信号、组合、执行和净收益逐层对齐。

12 / Distinguish two correlation questions

因子之间的相关，和因子预测收益的关系

第三讲已经检查过因子信息是否重叠。这一讲需要再次明确：一张矩阵的两边若都是当期因子，它回答的是特征共同变化；Rank IC的一边是当期因子、另一边是未来收益，回答的是预测关系。两者不应混成同一种“有效性分数”。

统计量比较对象用途
因子Pearson相关同日F₁与F₂了解线性冗余、方向符号与重复暴露。
因子Rank IC同日F与其后Y了解与未来收益排名的单调对应关系。

信息重叠不直接决定删哪一个

相关性高，提示因子可能重复强调某类特征；相关性低，也不证明两者都能预测收益。判断保留哪些因子，需要金融含义、增量信息、稳定性、样本外证据及后续成本检验。本课先识别问题，并不按这一张模拟矩阵自动筛选或优化权重。

方向乘以−1会翻转某些相关符号；MAD裁剪可能改变线性相关；在相同完整样本和正标准差下，单独做正尺度Z-score不会改变Pearson相关。因此每张图应写明原始值、裁剪值、Z值还是方向得分，避免把处理阶段差异误读成研究发现。

13 / TIME-ORDERED VALIDATION

把规则冻结，再问未使用的数据会怎样回答

研究最容易自我说服的地方，是不断在同一段历史里尝试窗口、方向、因子组合和股票范围，最后只留下表现最好的一版。如果用来选择方案的数据又被用来证明成功，结论已经受到挑选过程影响。时间顺序的开发、验证和最终测试，目的是让“提出规则”和“评价未使用数据”尽量分开。

阶段可以做什么应保留什么记录
开发依据金融逻辑提出有限假设，检查数据与计算，比较预先规划的候选。尝试过哪些窗口、方向、样本和失败方案。
验证帮助选择或拒绝开发出的方案；修改后要承认验证数据已参与选择。选择理由、更新内容与参数版本。
最终测试在关键规则冻结后评价尚未用于选择的数据。冻结时间、一次完整结果、正面与负面证据。

第三讲固定了因子定义和教学方向，本讲不会看到测试收益后再反转符号。若最终测试表现不理想，正确结果可以是“当前证据不足”“关系不稳定”或“原假设未被支持”。提出新假设并不被禁止，但原测试数据已经不再是未使用的证据，需要新的研究设计与新的未使用样本。

时间切分不只切信号日，还要看标签终点

假设开发区间在某个日期结束，某条开发期因子的未来20期收益却要等进入验证区间后才能知道。如果声称“在开发截止时已经完成评价和选方向”，就不能使用这条尚未成熟的标签。只按信号日筛选，会把区间外的未来信息偷偷带入开发过程。

因此，本课的示意审计同时检查因子日与标签终点：两者都必须落在被声明的区间内，才算该阶段已成熟的评价记录。跨界标签进入隔离说明，而不是补零或把最后可见价格当作20期终点。历史因子窗口向前借用此前已知数据则不同：验证日使用此前20期价格，并不会仅因这些价格位于开发期就变成泄漏。

import pandas as pd

dates = pd.bdate_range("2024-01-02", periods=80)               # 1. 模拟网格，非A股日历
grid = pd.DataFrame({"trade_date": dates, "position": range(80)})
grid["label_end_position"] = grid["position"] + 20            # 2. 未来20期间隔终点
grid["factor_warmup_ready"] = grid["position"] >= 20          # 3. 忽略额外缺口的最好情况
splits = {"develop": (0, 40), "validation": (40, 60), "test": (60, 80)}
for name, (start, end) in splits.items():                     # 4. 半开区间[start,end)
    belongs = grid["position"].ge(start) & grid["position"].lt(end)
    mature = belongs & grid["label_end_position"].lt(end)
    xy_ready = mature & grid["factor_warmup_ready"]
    print(name, "mature label dates:", int(mature.sum()),
          "warm factor + mature label dates:", int(xy_ready.sum()))
# 预期：develop 20/0；validation 0/0；test 0/0
  1. 第1步只用模拟日期的位置解释边界，不把周一到周五序列冒称真实交易日历。
  2. 第2步记录标签需要看到哪里；第3步说明20期因子至少要到第20个位置才可能出现，实际缺口还会进一步缩小样本。
  3. 第4步对三个预先固定的半开区间检查。开发段只有前20个起点能在本段内看到未来20期终点，但这些起点尚未完成因子预热，因此没有同时可用的X–Y日期。
  4. 验证和测试各只有20个价格位置，放不下完整20期前向收益；在这套教学划分中也没有成熟评价日期。报告不足，就是这个审计应得到的正确结果。
短样本不能靠改规则变长。

第三讲的8股、80个模拟日期足以练习计算流程，不能据此宣称已经完成可靠的三阶段实证检验。本课可以同时展示全部可评价日期的教学IC图，以及固定切分下的不足审计；前者不是后者的样本外成果。正式项目需要预先规划更长的历史与足够的成熟标签。

多次尝试，也需要进入实验记录

假设研究者尝试了很多窗口，最后一个方案偶然出现较高IC并不奇怪。若只报告成功方案的p值，读者看不到此前的挑选。至少应列出尝试清单、选择依据、数据版本和冻结参数；不要在看到结果后把探索性发现写成预先提出的假设。比较数量增加时，显著性也需要考虑多重检验问题。

这不要求初学者立刻掌握所有复杂校正方法。本讲先建立可复核的习惯：有限、事先说明的方案；开发与最终测试分开；跨界标签明确处理；负面结果完整报告。科研训练允许“尚无结论”，不允许把信息不足包装成确定性。

把“会调用函数”变成“会解释证据”

以下五题均为模拟教学问题。先写下样本、时间与统计口径，再运行代码。每题答案要同时说明数值含义和推断边界：一个可以计算的相关系数，未必是一份足以相信的预测证据。

练习1：手算一次Rank IC

五只虚构股票A–E的因子为12%、4%、−3%、8%、1%，未来20期收益为5%、−1%、−4%、7%、2%。按数值升序排名，求排名差平方和与Rank IC，并解释0.8是否足以证明长期有效。

展开排名、独立代码与评分标准 
import pandas as pd

sample = pd.DataFrame({"symbol": list("ABCDE"),
    "factor": [0.12, 0.04, -0.03, 0.08, 0.01],
    "future_return_20": [0.05, -0.01, -0.04, 0.07, 0.02]})
sample["factor_rank"] = sample["factor"].rank(method="average")
sample["return_rank"] = sample["future_return_20"].rank(method="average")
sample["d2"] = (sample["factor_rank"] - sample["return_rank"]) ** 2
n = len(sample)
rho = 1 - 6 * sample["d2"].sum() / (n * (n * n - 1))  # 本例没有并列
print(sample[["symbol", "factor_rank", "return_rank", "d2"]])
print("sum(d2) =", sample["d2"].sum(), "Rank IC =", rho)

因子排名为5、3、1、4、2，未来收益排名为4、2、1、5、3；平方差之和为4，所以ρ=0.8。这描述当前五个模拟样本中的正秩关系。只有一天五只股票，不能判断跨日期稳定性、样本外表现或成本后价值。评分10分：两列排名4分、平方差与0.8结果3分、正确说明证据边界3分。

练习2：出现并列排名，还能直接套简式吗？

某因子值为1、1、2、3、4，对应未来收益排名由高到低为5、4、3、2、1。请用平均秩计算相关，并比较无并列简式会给出什么不同数值。这里的1–5只是模拟排名单位，不是收益百分数。

展开并列处理与独立代码 
import pandas as pd

x = pd.Series([1., 1., 2., 3., 4.])
y = pd.Series([5., 4., 3., 2., 1.])
rx = x.rank(method="average")                       # 1. 前两个都取1.5
ry = y.rank(method="average")
correct = rx.corr(ry)                               # 2. 平均秩的Pearson相关
n = len(x)
invalid_shortcut = 1 - 6 * ((rx - ry) ** 2).sum() / (n * (n * n - 1))
print(rx.tolist())
print("correct =", round(correct, 6))
print("not applicable shortcut =", round(invalid_shortcut, 6))

平均秩为1.5、1.5、3、4、5，正确相关约−0.974679；把存在并列的数据硬放进无并列简式会得到−0.925。简式的前提已经不成立，不能选择看起来更符合预期的那个数。正式程序应使用经过处理的Spearman计算，并报告并列与唯一值数量。评分10分：平均秩3分、正确计算3分、指出简式前提与记录要求4分。

练习3：ICIR的分母为零时怎么办？

对序列−0.10、0.02、0.04、0.06、0.18计算平均IC、样本标准差和每期ICIR。再把它换成六个0.04，解释为什么不能把后者报告为无限可靠。

展开计算与零尺度规则 
import math
import pandas as pd

def safe_icir(values):
    s = pd.Series(values, dtype="float64").replace(
        [float("inf"), float("-inf")], float("nan")).dropna()
    if len(s) < 2 or s.nunique() <= 1:             # 1. 信息不足或常量
        return float("nan")
    sd = s.std(ddof=1)                              # 2. 样本标准差
    return s.mean() / sd if math.isfinite(sd) and sd > 0 else float("nan")

a = pd.Series([-0.10, 0.02, 0.04, 0.06, 0.18])
print(round(a.mean(), 6), round(a.std(ddof=1), 6), round(safe_icir(a), 6))
print(pd.isna(safe_icir([0.04] * 6)))                # True：保留缺失

第一组均值0.04、样本标准差0.10、ICIR 0.40。常量序列没有可用于这个比率的正离散程度，返回缺失并记录原因。一个小样本里的平坦序列也不能证明未来没有变化。评分10分：数值与ddof口径5分、零分母规则3分、推断边界2分。

练习4：五组收益“总体向上”，就可以说单调吗？

某次模拟截面五组的未来20期平均收益依次为−1.0%、0.5%、0.2%、1.5%、0.7%，人数依次为2、1、1、1、2。判断是否单调递增；计算Q5−Q1；说明这能否直接画成策略日净值。

展开数值核对与图形解释 
import pandas as pd

groups = pd.DataFrame({"group": ["Q1", "Q2", "Q3", "Q4", "Q5"],
    "mean_future_return_20": [-0.01, 0.005, 0.002, 0.015, 0.007],
    "n": [2, 1, 1, 1, 2]})
spread = groups.loc[4, "mean_future_return_20"] - groups.loc[0, "mean_future_return_20"]
print(groups)
print("monotonic:", groups["mean_future_return_20"].is_monotonic_increasing)
print("Q5 minus Q1:", f"{spread:.2%}", "total stocks:", groups["n"].sum())

它并不单调：Q2到Q3下降，Q4到Q5也下降。极端组均值差为1.7个百分点，但每组仅1–2只股票，个别样本就能明显改变图形。这是一个截面的前向价格收益差；若跨日期窗口重叠，也不能把这些20期收益当作独立日收益累乘。第五讲才定义真实持仓、执行与成本。评分10分：非单调解释3分、差值与单位2分、人数与策略边界5分。
